# shell介绍

shell 是 Unix/Linux 系统中用户与内核之间的接口程序，属于命令解释器；

## 常见shell类型对比

| shell | 描述                                          | 特点                                                         | 典型场景                     | Ubuntu下               |
| ----- | --------------------------------------------- | ------------------------------------------------------------ | ---------------------------- | ---------------------- |
| Bash  | Linux 系统中最常用的默认交互式 shell          | 兼容传统 shell 脚本<br/>支持命令补全、历史记录、自定义别名<br/>功能丰富且高度可配置 | 日常命令行操作、脚本编写     | 默认用户登录 shell     |
| sh    | 符合 POSIX 标准的基础 shell用于保证脚本兼容性 | 语法简单，功能精简<br/>不支持交互式增强功能（如补全）        | 系统服务启动脚本、兼容性脚本 | 实际指向dash(轻量替代) |
| Zsh   | 功能强大的现代化 shell, 扩展了 bash 的特性    | 智能命令补全、主题美化<br/>支持插件化定制<br/>兼容 bash 大部分语法 | 开发者、追求高效交互的用户   | 需手动安装             |
| Fish  | 以交互友好性为核心的 shell，强调易用性        | 自动命令建议、语法高亮<br/>配置简单，开箱即用<br/>语法与 bash 不完全兼容 | 新手用户、注重交互体验的场景 | 需手动安装             |

# 第一个shell脚本

## 文件扩展名

通常习惯用 .sh 作为扩展名，不是强制要求。关键在于文件开头的 shebang 行;
## shebang 行

一般写成 #!/bin/bash ，这行的作用是指定执行脚本的 shell 解释器路径;

## 注释

单行注释: ：以 # 开头，#后面的是注释内容；

多行注释: 在 Bash 中可以用 <<EOF 和 EOF 包裹起来

## 运行方式

赋予执行权限后直接运行: 无序额外启动解释器, 需要手动赋予权限, 环境变化,权限可能需要重新设置, 适合环境中稳定部署, 高效且频繁执行的固定任务脚本

shell解释器运行: 无需设置权限, 可灵活选用不同shell解释器, 每次执行需要指定解释器, 启动开销大, 适合脚本开发测试阶段, 验证脚本在不同shell下运行情况

使用source执行: 当前shell环境内执行, 不产生新紫禁城, 脚本内变量可直接用于当前环境, 不能脱离当前shell环境独立运行, 加载或更新shell配置文件, 需要在当前魂晶立即应用脚本配置的场景

# shell中的变量

## 命名规则

变量名由字母、数字和下划线组成，且不能以数字开头

## 赋值

变量名 = 初始值
变量名 =' 初始值'
变量名 ="初始值"

## 调用方式

使用$符号加上变量名来引用变量的值, 推荐使用\${变量名}形式, 可避免歧义

shell中变量没有数据类型, 均视为字符串, 如num=12345678

定义变量时, 两边不允许有空格

一般情况下, 三种定义方式可通用, 当变量初始值包含空格时, 需要用单引号或双引号括起来

## 变量类型

### 系统变量

系统设置, 所有脚本可访问

\$HOME,\$USER, 全大写

### 用户变量

在脚本中创建并赋值, 仅在当前shell脚本或会话中有效

赋值与使用: 变量名=值, 引用时使用\$变量名或\${变量名}, 删除使用unset 变量名, 小写或驼峰式

### 环境变量

可在当前shell进程及其子进程都能访问的变量

声明方法: export 变量名=变量值 全大写

### 局部变量

仅在当前shell或脚本中有效, export默认隐式局部变量, 局部变量只在函数内有效, 函数执行完毕后, 局部变量就会被销毁 小写或驼峰式

## 特殊变量与位置参数

$0: 表示当前脚本名称

$?: 表示上一条命令的退出状态码，0 表示命令执行成功，非 0 表示命令执行失败

\$1 - \$9: 依次对应执行脚本时传递的第 1 - 9 个参数；

10及以上: ${10}表示第10个参数

$*: 包含执行脚本时传递的所有参数(不含脚本文件名)，在循环中会将所有参数当作一个整体处理

$@:同样表示执行脚本时传递的所有参数(不含脚本文件名)，在循环中会逐个处理每个参数;

$#: 表示执行脚本时传递的参数个数(不含脚本文件名)

## 修饰变量关键字

- readonley: 用于修饰变量，使其成为只读属性，赋值后不可再修改, 

只读变量不能使用 unset 删除, 重新定义同名变量也无法覆盖只读属性

- unset关键字: 用于取消变量的定义，删除后变量引用返回空值

对 readonly 修饰的变量使用 unset 会报错, 若变量未定义，使用 unset 不会报错

- local: 在函数内部使用，用于创建局部变量，仅在函数内有效

函数外使用 local 会报错

语法: 数组名=(元素1 元素2 元素3 ...)

逐个赋值: 数组名[索引]=元素

单个元素: ${数组名[索引]}

${数组名[*]}: 将所有元素视为整体字符串, 元素间默认空格

- 末尾添加: 数组名+=("新元素")
- 指定索引添加: 数组名[新索引]="新元素"

数组名[索引]="新值"

## 删除元素

unset 数组名[索引]

## 截取数组

${数组名[@]:起始索引:长度} 长度可选, 缺省到末尾

# read命令

read是shell编程里的内置命令，用于从标准输入(一般是键盘)或文件中读取数据，并赋值给变量

- 语法: read 选项 变量1 变量2
- 说明: 
- 选项用于控制读取行为，变量名用于存储读取的数据；若不指定变量名，输入会被赋值到环境变量 REPLY(用于临时存储 read 命令的输入结果)；

- 读取多个数据时，用空格或 Tab 键分隔，回车键是输入结束标志，非数据分隔符
- 引用变量时用双引号包裹，防止空值或特殊字符问题；
- 用户直接回车会使变量为空，可用参数扩展设默认值，格式为${变量名:-默认值}

- 字符转义: 默认反斜杠(\)是转义符，要其作普通字符用-r选项

| 选项 | 功能描述                                                     | 示例                                        |
| ---- | ------------------------------------------------------------ | ------------------------------------------- |
| -p   | 显示提示信息，引导用户输入                                   | read -p "输入姓名：" name → 显示 输入姓名： |
| -s   | 静默模式，输入内容不显示(适用于密码等敏感信息)               | read -s -p "密码：" pass → 输入时屏幕无显示 |
| -n N | 读取 N 个字符后自动结束，无需按回车                          | read -n 2 input → 输入两个字符后立即结束    |
| -t N | 设置超时时间(秒)，超时后退出并返回非零状态码                 | read -t 3 input → 3 秒无输入则自动退出      |
| -a   | 将输入按空格分割为数组，存入指定变量                         | read -a arr → arr[0]=abc, arr[1]=def        |
| -r   | 禁止反斜杠转义(将反斜杠视为普通字符)                         | read -r home → 输入C:\home，home=C:\home    |
| -d   | 指定行结束符(默认为回车) read -d ':' input → 输入 a: 时，input=a | read -d ':' input → 输入 a: 时，input=a     |

# echo命令

echo 命令是 shell 脚本中最常用的输出工具，用于向终端打印文本或变量值、配合重定向符号（如 >、>>将内容写入文件等等)

- 语法: echo 选项 变量/字符串

- 引号区分解析：单引号保留字面量，双引号解析变量，需转义时用 -e
- 变量边界明确：变量名后接字符时用 ${var} 避免解析错误
- 转义需显式启用：默认不解析 \n、\t，需加 -e 选项\
- 复杂格式用 printf：echo 格式控制有限，复杂场景用 printf

| 选项 | 作用                                            | 示例                     |
| ---- | ----------------------------------------------- | ------------------------ |
| -e   | 启用转义字符解析（如 \n、\t）                   | echo -e "第一行\n第二行" |
| -n   | 不换行输出（默认会自动添加换行符）              | echo -n "Loading..."     |
| -E   | 禁用转义字符解析(默认行为, 部分shell需显示指定) | echo -E "a\nb" 输出a\nb  |

转义字符: \033[31m 红色文本(搭配\033[30m重置)

# 条件判断

## if语句

- 基本结构

```shell
if ((表达式));then
	shell语句
fi
```

当((表达式))的结果为非零值(即条件为真)时,执行then后面的语句

((表达式))是bash特有的算数表达式, 支持+,-,*,/,>,<等运算符

## if-else语句

- 基本结构

```shell
if ((表达式));then
	shell语句1
else
	shell语句2
fi
```

## if-elif-else语句

- 基本结构

```shell
if ((表达式1));then
	shell语句1
elif ((表达式2));then
	shell语句2
else
	shell语句3
fi
```

如果所有表达式都为假，此时有else，则执行else后的语句；没有else，则直接退出程序

## test命令

在 shell 编程里，test 命令的作用是比较数值和字符串、对条件进行测试等，常与if语句配合使用

- 语法: test 表达式或[ 表达式 ]

- 注意事项

  > 使用方括号 [ ] 这种形式时，方括号和表达式之间必须有空格
  >
  > 在使用变量时，建议将变量用双引号引起来，这样可以防止变量为空或包含空格时出现问题
  >
  > test 命令的返回状态码为0 表示条件成立，非0 表示条件不成立，和其他命令返回值规则是一样的
  >
  > test命令本身是一个elf的可执行程序，当执行test命令时，后边的数据作为参数传递给test程序中的main函数，main函数中有两个参数argc和argv,通过这两个参数可以获得执行test程序时传递的参数，因此在表达式中，出现参数，运算符，中括号前后必须添加空格

## [[ ]]的使用

在 shell 编程中，[[ ... ]] 是 Bash 提供的高级条件测试语法，比传统的 [ ... ] 更强大、更灵活

- 基本语法

```shell
if [[ 条件表达式 ]];then
	shell语句
fi
```

- 无需转义特殊字符, 可直接使用
- 支持短路求值
- 语法更接近自然逻辑, 可直接使用逻辑符&& || 
- 安全处理未定义变量, 未定义变量会将其视为空串, 避免但括号可能触发的语法错误

| (( ... ))      | (( a == b ))       | 不适用                 | 不适用         | 仅适用于 Bash 等支持算术扩展的 shell                         | 专注于数值计算、循环计数等纯算术运算场景                     |
| test ([ ... ]) | [ "\$a" -eq "$b" ] | [ "\$str1" = "$str2" ] | [ -f "$file" ] | 适用于传统 shell 脚本，各类 Unix 系统及不同版本 shell 兼容性强 | 对兼容性要求极高，需在老版本shell 或不同类型 shell 环境中稳定运行的脚本 |

# case...in语句

在 shell 编程中，case...in 语句是一种多路分支结构，用于根据不同的条件执行相应的代码块。它类似于其他编程语言中的 switch - case 语句，能让代码在面对多种情况时，清晰、简洁地进行逻辑处理

- 语法:

```shell
case 变量 in
	模式1)
		命令序列1
		;;
	模式2)
		命令序列2
		;;
	*)
		默认命令序列
		;;
esac
```

# select...in语句

select...in 是 shell 脚本中用于创建 交互式菜单 的专用命令，主要用于引导用户通过键盘输入选择预设选项。它会自动为每个选项生成编号（从 1 开始），用户输入对应数字即可触发相应操作，适合需要频繁与用户交互的场景（如脚本配置、功能选择等）

- 语法

```shell
select 变量名 in 选项1 选项2 选项3...
do
	命令序列
	[break] #可选, 用于退出循环
done
```

# for循环

适用于已知要遍历的元素集合（如数组、列表）或明确循环次数的场景，通过依次迭代集合元素或按指定数字范围来执行循环体;

- 语法

```shell
# 遍历列表
for 变量 in 列表或数组元素;do
	命令1
	命令2
	...
done

# 数字范围循环
for ((初始值; 条件; 增量或减量));do
	命令1
	命令2
	...
done
```

# while循环

根据条件判断结果决定是否执行循环体，只要条件为真就持续循环，直到条件为假时结束，适用于条件动态变化或不确定循环次数的情况；

- 语法

```shell
while 条件判断;do
	命令1
	命令2
	...
done
```

在这个结构中，条件判断可以是各种各样的测试，像数值比较、字符串比较、文件状态检测等；

只要条件判断的结果为真（返回状态码 0），循环体就会一直执行；一旦条件判断结果为假（返回状态码非 0），循环就会终止；

# until循环

与while循环相反，until循环基于条件判断结果决定是否执行循环体，不过是条件为假时持续循环，一旦条件变为真就结束循环，适用于需要等待某个条件达成的场景；

- 语法

```shell
until 条件判断;do
	命令1
	命令2
	...
done
```

在需要等待特定条件从假变为真的场景中，逻辑表达更自然清晰，避免在while循环中使用双重否定条件（例如不必写while [ ! -f file.txt ]，而是直接用until [ -f file.txt ]);

# break 和 continue

break的作用是强制终止当前所在的循环，无论循环条件是否仍然满足，程序都会立即跳出该循环，然后继续执行循环体后面的代码；

continue的作用是跳过当前这一轮循环体中剩余的代码，直接开始下一轮循环；程序会忽略continue后面的语句，回到循环的起始处重新判断循环条件，若条件满足则继续执行下一轮循环

# 函数

在 shell 编程中，函数是一种将多次使用的代码块封装起来的机制，它可以提高代码的复用性和可维护性

- 语法

```shell
# 标准格式
function 函数名(){
	命令1
	命令2
	...
	[return 返回值] #可选, 返回值范围0-255
}

# 简化格式
函数名(){
	命令1
	命令2
	...
	[return 返回值] #可选, 返回值范围0-255
}
```

- 函数调用: 直接使用函数名即可调用，若函数需要参数，直接跟在函数名后面，参数之间用空格分隔

- 函数参数:

> $1, $2, ..., $n：表示第 1 到第 n 个参数
>
> $0：表示脚本本身的名称，在函数内部使用时，它仍然表示脚本名，而不是函数名
>
> $#：表示参数的个数
>
> \$@或\$*：表示所有参数，\$@将参数视为独立的个体，\$\*将所有参数视为一个整体

## 返回值

- 通过return语句返回状态码

  > 状态码可通过$?变量获取，但仅能是整数
  >
  > return语句会立即终止函数执行，类似exit但仅作用于函数
  >
  > 主要用于表示执行状态，而非数据结果
  >
  > 仅能返回整数（0-255）

- 通过echo输出返回结果

```shell
function value(){
	echo $(($1 + $2))
}
ret=$(value 1 2)
```

> 通过echo将结果输出到标准输出，再用\$(...)或反引号`捕获, 一般使用\$(...)
>
> 支持任意类型数据（字符串、数字、多行内容）
