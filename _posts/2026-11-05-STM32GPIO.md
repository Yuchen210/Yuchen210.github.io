## 1 GPIO 控制器介绍

### 1.1 什么是 GPIO

**GPIO（General‑Purpose Input Output）通用输入输出**，是单片机通用引脚接口。引脚可配置输入或者输出，用来和外部器件（传感器、LED、按键、继电器等）完成数字通信。

### 1.2 STM32F407 GPIO 硬件概况

- 芯片共 176 引脚，GPIO 引脚合计**140 个**

- 分为 9 组：

  ```
  GPIOA ~ GPIOI
  ```

  - GPIOA~GPIOH：每组 16 个引脚（Pin0‑Pin15）
  - GPIOI：12 个引脚（Pin0‑Pin11）

### 1.3 GPIO 六种工作模式汇总

表格

| 大类     | 模式         | 说明                                               |
| -------- | ------------ | -------------------------------------------------- |
| 输出模式 | 推挽输出     | PMOS+NMOS 同时可用，可输出高 / 低电平，驱动能力强  |
|          | 开漏输出     | 仅 NMOS 工作，高电平需要外部上拉电阻；支持线与     |
| 输入模式 | 浮空输入     | 无上拉、下拉，引脚高阻态                           |
|          | 上拉输入     | 内部接上拉电阻，默认高电平                         |
|          | 下拉输入     | 内部接下拉电阻，默认低电平                         |
| 模拟模式 | 模拟输入输出 | 用于 ADC、DAC，关闭数字施密特触发器                |
| 复用模式 | 外设复用     | 引脚交由片内外设（USART / SPI / I2C / 定时器）控制 |

### 1.4 GPIO 内部框图关键部件

1. **TTL 施密特触发器**：输入信号整形，把模拟抖动信号转为干净数字 0/1；
2. **输入数据寄存器 IDR**：读取外部引脚电平；
3. **输出数据寄存器 ODR**：输出电平；
4. **置位复位寄存器 BSRR**：单独置 1 / 清 0 引脚，避免读改写；
5. **输出驱动器（PMOS、NMOS 管）**：实现推挽、开漏输出；
6. **内部上拉 / 下拉电阻**：输入模式配置；
7. **复用通路**：连接 UART、SPI 等外设；
8. **ESD 保护二极管**：IO 引脚静电保护，钳位电压。

## 2 GPIO 输入模式

### 2.1 TTL 施密特触发器

作用：对输入的抖动、模拟波形整形，输出标准数字方波。

- 高阈值：`0.7 × VDD`（典型 2.31V，VDD=3.3V），高于该电压识别为逻辑高电平
- 低阈值：`0.3 × VDD`（典型 0.99V，VDD=3.3V），低于该电压识别为逻辑低电平
- STM32F4 支持**5V 容忍 IO**：输入耐压 `-0.3V ~ 5.5V`。

> 信号经过施密特触发器之后才会存入输入数据寄存器 IDR。

### 2.2 浮空输入

- 内部**不接上拉、下拉电阻**，引脚处于高阻状态。
- 引脚悬空时电平不稳定，容易受干扰；适合外部电路已经确定电平的场景。

### 2.3 上拉输入

- 内部接通上拉电阻，引脚**默认电平为高电平**。
- 适合检测外部拉低信号（按键按下把引脚拉到 GND），按键松开引脚维持高电平。

### 2.4 下拉输入

- 内部接通下拉电阻，引脚**默认电平为低电平**。
- 适合检测外部拉高信号，外部器件输出高电平时引脚变为高。

## 3 三极管与 MOS 管基础

### 3.1 二极管

单向导电半导体器件。

- 硅管导通电压 0.5‑0.7V，导通压降 0.6‑0.8V；
- 正向偏置导通，反向截止。

### 3.2 晶体三极管（BJT，电流控制）

三极管三个电极：**基极 B、集电极 C、发射极 E**；三种工作状态。

1. **截止状态**：发射结电压不足，几乎无电流，开关断开；
2. **放大状态**：发射结正偏、集电结反偏；基极小电流控制集电极大电流，用于信号放大；
3. **饱和导通**：基极电流足够大，集电极电流不再放大，C‑E 近似导通，相当于开关闭合。

- NPN：基极高电平导通；
- PNP：基极低电平导通。

> 三极管是**电流控制器件**，需要基极驱动电流。

### 3.3 MOS 管（场效应管，电压控制）

三个电极：**栅极 G、漏极 D、源极 S**

- NMOS：G 相对 S 施加正电压，管子导通；
- PMOS：G 相对 S 施加负电压，管子导通。

> MOS 是**电压控制型器件**，栅极几乎不取电流，功耗低，适合高速开关。

表格

| 特性     | 三极管（BJT）        | MOS 管                 |
| -------- | -------------------- | ---------------------- |
| 控制方式 | 电流控制             | 电压控制               |
| 驱动功耗 | 较高                 | 极低                   |
| 开关速度 | 较慢                 | 快                     |
| 典型应用 | 低频放大、小功率开关 | 高速开关电源、电机驱动 |

## 4 GPIO 输出模式

GPIO 输出驱动器由 PMOS、NMOS 一对 MOS 管组成。

### 4.1 推挽输出 Push‑Pull

- PMOS、NMOS 都可以参与工作。
- 输出低电平：NMOS 导通，PMOS 截止 → IO 接 VSS (GND)；
- 输出高电平：PMOS 导通，NMOS 截止 → IO 接 VDD (3.3V)。

✅优点：输出高低电平驱动能力强； ❌缺点：**不能直接实现线与**，多个推挽输出不能直接并联。

### 4.2 开漏输出 Open‑Drain

- PMOS 永久关闭，

  只有 NMOS 管

  。

  - 输出逻辑 1：NMOS 截止 → IO 为**高阻态**；
  - 输出逻辑 0：NMOS 导通 → IO 拉到 GND。

> ⚠️想要输出高电平，**外部必须接上拉电阻**，由外部上拉电阻提供高电平。

✅特点：

1. 支持**线与逻辑**：多个开漏引脚并联；只要任意一个输出低，总线就被拉低；全部截止总线才是高电平。I2C 总线就是典型开漏 + 线与。
2. 可以实现电平转换（3.3V 芯片控制 5V 外部器件）。

### 4.3 ODR 与 BSRR 寄存器区别

1. ODR（输出数据寄存器）

   读写方式：读‑改‑写流程

   - 读取 ODR 当前值 → 修改需要操作的位 → 写回 ODR。
   - 缺点：多任务并发时，读改写容易出现竞态冲突。

2. BSRR（置位 / 复位寄存器，只写）

   - bit [0‑15]：置位，写 1 对应引脚输出高；写 0 无效；
   - bit [16‑31]：复位，写 1 对应引脚输出低；写 0 无效。
   - 优势：不需要读原有寄存器，直接置 1 清 0，避免读改写风险，推荐优先使用 BSRR。

> BSRR 是**只写寄存器**，读 BSRR 没有意义。

## 5 模拟模式

- 关闭 TTL 施密特触发器，关闭输出驱动 MOS 管。
- IO 引脚直接把外部模拟电压送入内部 ADC 模块；DAC 输出模拟信号也走模拟通路。
- 使用 ADC/DAC 外设，GPIO 必须配置为**模拟模式**。

## 6 复用模式

- 引脚不再受 GPIO 控制器控制；交由对应的片内外设硬件接管引脚电平。
- 示例：USART TX/RX、SPI SCK/MOSI、I2C SDA/SCL、定时器 PWM 输出。
- 需要配置`AFRL / AFRH`复用功能寄存器选择对应的外设功能。

## 8 HAL 库 GPIO 接口

### 8.1 GPIO 初始化结构体

```
typedef struct {
  uint32_t Pin;        // 引脚号，GPIO_PIN_0 ~ GPIO_PIN_15
  uint32_t Mode;       // 模式：输入/输出/复用/模拟
  uint32_t Pull;       // NO_PULL / PULL_UP / PULL_DOWN
  uint32_t Speed;      // 输出速度：低速/中速/高速
  uint32_t Alternate;  // 复用功能编号，复用模式才生效
} GPIO_InitTypeDef;
```

### 8.2 引脚状态枚举

```
typedef enum {
  GPIO_PIN_RESET = 0,   // 低电平
  GPIO_PIN_SET          // 高电平
} GPIO_PinState;
```

### 8.3 核心 API 函数

表格

| 函数               | 原型                                                         | 功能                                         |
| ------------------ | ------------------------------------------------------------ | -------------------------------------------- |
| HAL_GPIO_Init      | `void HAL_GPIO_Init(GPIO_TypeDef *GPIOx, GPIO_InitTypeDef *GPIO_Init)` | 初始化 GPIO 引脚模式、上下拉、速度、复用功能 |
| HAL_GPIO_ReadPin   | `GPIO_PinState HAL_GPIO_ReadPin(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin)` | 读取引脚输入电平，返回 SET / RESET           |
| HAL_GPIO_WritePin  | `void HAL_GPIO_WritePin(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin, GPIO_PinState PinState)` | 设置引脚输出高 / 低电平                      |
| HAL_GPIO_TogglePin | `void HAL_GPIO_TogglePin(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin)` | 翻转引脚电平（输出取反）                     |

> 注意：使用 GPIO 之前，**必须打开对应 GPIO 组的 RCC 时钟**，否则寄存器读写无效。

## 9 GPIO 硬件应用案例

### 9.1 LED 灯控制

硬件：LED 阳极接 3V3 串联限流电阻，阴极接单片机 GPIO 引脚。

- 引脚输出**低电平** → LED 两端形成压差，灯点亮；
- 引脚输出**高电平** → 压差为 0，LED 熄灭。 配置要点：GPIO 配置**推挽输出模式**。

### 9.2 按键输入

硬件：按键一端接 GND；IO 引脚外接 10k 上拉电阻 + 100nF 滤波电容。

- 按键松开：引脚被上拉为高电平；
- 按键按下：引脚直接连通 GND，变为低电平。 配置要点：GPIO 配置**上拉输入模式**（也可以外部上拉，配置浮空输入）。

> 电容作用：抑制按键机械抖动。

### 9.3 调压信号发生器（开漏输出应用）

IO 配置为**开漏输出模式**。

- NMOS 导通时引脚拉到 GND，输出 0V；
- NMOS 截止时引脚为高阻态，输出电压完全由外部电阻分压网络决定。 \(V_{SW‑OD}=\frac{R112}{R110+R111+R112} × 5V\)

> 可以输出介于 0‑5V 之间多种电压，实现可调电平。

### 9.4 继电器驱动

继电器线圈需要较大电流，单片机 IO 不能直接驱动，使用 NPN 三极管作为开关。

- GPIO 输出高电平 → NPN 三极管导通，继电器线圈通电，触点吸合；
- GPIO 输出低电平 → NPN 三极管截止，继电器线圈断电，触点断开。
- 线圈并联续流二极管，吸收继电器断开瞬间反向感应电动势，保护三极管。

> 注意：继电器线圈供电可以是 5V，和单片机 3.3V 系统电平不同，做好隔离。
