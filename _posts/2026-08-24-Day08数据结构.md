# 线性表的顺序表示和实现

## 线性结构的特点:

1. 存在唯一的一个被称作“第一个”的数据元素
2. 存在唯一的一个被称作“最后一个”的数据元素
3. 除第一个之外，集合中的每个元素均只有一个前驱
4. 除最后一个以外，集合中的每个数据元素均只有一个后继

## 顺序表

### 初始化

#define LIST_INIT_SIZE 100

### 插入

> 先判断位置是否合法, 插入的位置应该在i和length+1之间
>
> 再判断顺序表是否已满, 如果已满扩容空间
>
> 找到插入的位置, 将插入位置之后的元素后移一位, 从末尾开始, 向前
>
> 将新元素插入, 更新长度

```c
int ListInsert_Sq(SqList *L, int i, ElemType e)
{
    // 判断插入位置是否合法，i 的值应该在 1 到 L.length+1 之间
    if (i < 1 || i > L->length + 1)
    {
        return ERROR;
    }
    // 如果顺序表已满，需要重新分配内存空间
    if (L->length >= L->listsize)
    {
        ElemType *newbase = (ElemType *)realloc(L->elem, (L->listsize + LISTINCREMENT) * sizeof(ElemType));
        if (!newbase)
        {
            exit(OVERFLOW); // 内存分配失败，退出程序
        }
        // 更新顺序表的基地址和容量
        L->elem = newbase;
        L->listsize += LISTINCREMENT;
    }
    // 找到插入位置的地址
    ElemType *q = &(L->elem[i - 1]);
    // 将插入位置之后的元素向后移动一位
    for (ElemType *p = &(L->elem[L->length - 1]); p >= q; --p)
    {
        *(p + 1) = *p;
    }
    // 将新元素插入到指定位置
    *q = e;
    ++L->length; // 更新顺序表的长度
    return OK;
}
```

### 删除

> 判断删除的位置是否合法, 应在1到length之间
>
> 找到删除的位置, 将值返回给e
>
> 将删除位置之后的元素向前移动一位, 更新顺序表长度

```
int ListDelete_Sq(SqList *L, int i, ElemType *e)
{
    // 判断删除位置是否合法，i 的值应该在 1 到 L.length 之间
    if (i < 1 || i > L->length)
    {
        return ERROR;
    }
    // 找到删除位置的地址
    ElemType *p = &(L->elem[i - 1]);
    // 将删除位置的元素赋值给 e
    *e = *p;
    // 将删除位置之后的元素向前移动一位
    ElemType *q = L->elem + L->length - 1;
    for (++p; p <= q; ++p)
    {
        *(p - 1) = *p;
    }
    // 更新顺序表的长度
    --L->length;
    return OK;
}
```

### 顺序表的合并

> 三个指针, 初始化pa, pb并让pa和pb指向la和lb
>
> 初始化Lc, 其大小为La和Lb之和
>
> 合并两个顺序表, 那个小存入那个, 结束条件用末尾指针判断
>
> 最后将剩余的合并到新的顺序表中

```c
void MergeList_Sq(SqList *La, SqList *Lb, SqList *Lc)
{
    ElemType *pa, *pb, *pc;
    ElemType *pa_last, *pb_last;
    // 初始化指针 pa 和 pb，分别指向顺序表 La 和 Lb 的第一个元素
    pa = La->elem;
    pb = Lb->elem;
    // 初始化 Lc 的大小，并分配内存空间
    Lc->listsize = Lc->length = La->length + Lb->length;
    Lc->elem = (ElemType *)malloc(Lc->listsize * sizeof(ElemType));
    if (!Lc->elem)
    {
        exit(OVERFLOW); // 如果内存分配失败，退出程序
    }
    pc = Lc->elem; // 初始化指针 pc，指向顺序表 Lc 的第一个元素
    // 初始化指针 pa_last 和 pb_last，分别指向顺序表 La 和 Lb 的最后一个元素
    pa_last = La->elem + La->length - 1;
    pb_last = Lb->elem + Lb->length - 1;
    while (pa <= pa_last && pb <= pb_last)
    { // 合并两个顺序表，直到其中一个顺序表遍历完
        if (*pa <= *pb)
        {
            *pc++ = *pa++; // 将较小的元素放入 Lc
        }
        else
        {
            *pc++ = *pb++;
        }
    }
    while (pa <= pa_last)
    { // 如果pa没有到达最后一个元素，将剩余的元素插入到Lc中
        *pc++ = *pa++;
    }
    while (pb <= pb_last)
    { // 如果pb没有到达最后一个元素，将剩余的元素插入到Lc中
        *pc++ = *pb++;
    }
}
```



## 线性链表

一个节点包括两个域：存储数据元素信息的域称为数据域；存储直接后继存储位置的域称为指针域

![线性链表](/../assets/pictures/线性链表.png)

### 应用场景

1. 动态数据结构：当你需要一个可以动态调整大小的数据结构时，线性链表非常适合。与数组相比，链表可以方便地在运行时插入和删除元素，而无需预先定义大小

2. 频繁的插入和删除操作：在需要频繁进行插入和删除操作的场景中，链表的性能优于数组。例如，任务调度、操作系统中的进程管理等场景
3. 实现其他数据结构：链表常用于实现其他复杂数据结构，如栈、队列、哈希表等。这些数据结构的基本操作可以通过链表轻松实现
4. 处理不确定数量的数据：例如，处理用户输入的字符串或数据流时，链表能够灵活地扩展以适应不同的数据量
5. 实现图的邻接表：在图的表示中，链表常用作邻接表的实现，以存储图的边和节点的关系
6. 内存管理：链表在内存管理中也很有用，例如，空闲内存块的链表管理，可以有效地跟踪和分配内存

### 插入节点

> 使用指针p指向头节点,
>
> 遍历链表, 找到i-1个节点, p为空或节点大于i-1结束,如果遍历到末尾说明位置不合法
>
> 创建新节点, 将节点插入后边

```c
int ListInsert_L(LinkList *L, inti, ElemTypee)
{
    LinkList p = *L; // 用指针 p 指向头节点
    intj = 0;
    // 遍历链表，直到找 到第 i-1 个节点
    while (p && j < i - 1)
    {
        p = p->next;
        ++j;
    }
    // 如果遍历到链表末尾，说明 i的值不合法，返回 ERROR
    if (!p || j > i - 1)
    {
        return ERROR;
    }
    // 创建一个新节点 s，将新节点插入到第 i-1 个节点之后
    LinkLists = (LinkList)malloc(sizeof(LNode)); // 为新节点分配内存
    if (!s)
    {
        returnERROR; // 如果内存分配失败，返回 ERROR
    }
    s->data = e;       // 将数据 e 插入到新节点中
    s->next = p->next; // 将新节点的 next 指向原来第 i个节点
    p->next = s;       // 将第 i-1 个节点的 next 指向新节点
    return OK;          // 插入成功，返回 OK
}
```

### 查找节点

int GetElem_L(LinkListL, inti, ElemType *e)

### 删除节点

> 遍历找到第i-1个节点, 如果到末尾说明位置不合法
>
> 返回删除的值, 然后令i-1个节点指向i+1, 释放第i个节点

```c
// 删除链表 L 中第 i个元素，并将其值存入 e
int ListDelete_L(LinkList *L, inti, ElemType *e)
{
    LinkListp = *L; // 指针 p 指向头节点
    LinkList q;      // 用于保存要删除的节点
    int j = 0;
    // 从头节点开始遍历链表，找到第 i-1 个节点
    while (p->next && j < i - 1)
    {
        p = p->next;
        ++j;
    }
    // 如果遍历到链表末尾，说明 i的值不合法，返回 ERROR
    if (!(p->next) || j > i - 1)
    {
        return ERROR;
    }
    // 删除第 i个节点，并将其值赋值给 e
    q = p->next;       // 保存要删除的节点
    p->next = q->next; // 将第 i-1 个节点的 next 指向第 i+1 个节点
    *e = q->data;      // 将被删除节点的值赋给 e
    free(q);           // 释放被删除节点的内存
    return OK;          // 删除成功，返回 OK
}
```

### 合并有序链表

> 定义两个节点分别指向a和b第一个节点, 再让c等于a的头节点.
>
> 当a和b都不为NULL时进行判断, 那个小让链表指向那个, 然后往后循环
> 最后令pc指向剩余不为空的链表
>
> 把b的头节点释放(a的头节点已经用来给c了)

```c
void MergeList_L(LinkList *La, LinkList *Lb, LinkList *Lc)
{
    LinkList pa = (*La)->next; // 指向链表 La 的第一个节点
    LinkList pb = (*Lb)->next; // 指向链表 Lb的第一个节点
    LinkList pc;               // 用于构建链表 Lc
    *Lc = pc = *La;           // 将 Lc 的头节点指向 La，并将 pc 也指向 La
    // 当 pa 和 pb 都不为 NULL 时，比较它们的值，将较小的节点插入到 Lc 中
    while (pa && pb)
    {
        if (pa->data <= pb->data)
        {
            pc->next = pa;
            pc = pa;
            pa = pa->next;
        }
        else
        {
            pc->next = pb;
            pc = pb;
            pb = pb->next;
        }
    }
    // 如果 pa 不为 NULL，将剩余的节点插入到 Lc 中
    pc->next = pa ? pa : pb;
    // 释放链表 Lb的头节点，避免内存泄漏
    free(*Lb);
}
```

### 节点插入

> 判断头节点为空或位置小于1返回错误
>
> ptr指向头节点, ptr到最后节点或i-1位, 遍历完之后如果i>1表示链表已到末尾, 位置不合法
>
> 创建新节点, 新节点next指向ptr->next, prior指向ptr, ptr->next指向新节点. 如果ptr不是第一个节点, 令ptr->next的prior指向新节点

```c
int InsertDulLinkList(DulLinkList *L, int i, ElemType e){
    //如果头节点为空或位置小于1则返回错误
    if(L == NULL && i < 1){
        return ERROR;
    }
    //ptr指向头节点
    DulLinkList ptr = *L;
    //遍历ptr到指定位置, ptr到最后节点或已经到第i-1位
    while(ptr->next != *L && i > 1){
        ptr = ptr->next;
        i--;
    }
    if(i > 1){
        return ERROR;
    }
    DulNode *newNode = (DulNode *)malloc(sizeof(DulNode));
    if(newNode == NULL){
        return OVERFLOW;
    }
    newNode->data = e;
    newNode->next = ptr->next;
    newNode->prior = ptr;
    
    if(ptr->next->prior != NULL){
        newNode->next->prior = newNode;
    }
    ptr->next = newNode;
    return OK;
}
```

### 节点删除

> 如果头节点为空或小于1位置非法
>
> ptr指向头节点, 遍历ptr, 自环双链表, 如果ptr->next->prior不为空(及下一个节点不是头节点及i > 1)
>
> ptr移动到需要删除的位置, 下一位不是头节点则下一位指向ptr上一位, ptr上一位指向下一位, 释放ptr

```c
int DeleteDulLinkList(DulLinkList *L, int i, ElemType *e){
    //如果头节点为空或位置小于1则返回错误
    if(L == NULL && i < 1){
        return ERROR;
    }

    //ptr指向头节点
    DulLinkList ptr = *L;

    //遍历ptr到指定位置, ptr到最后节点或已经到第i-1位
    while(ptr->next->prior != NULL && i > 1){
        ptr = ptr->next;
        i--;
    }

    //遍历完还没到位置返回错误
    if(i > 1){
        return ERROR;
    }

    //ptr向后到需要删除的位置
    ptr = ptr->next;
    //下一位不是头节点则下一位指向ptr上一位
    if(ptr->next->prior != NULL){
        ptr->next->prior = ptr->prior;
    }
    ///ptr上一位指向下一位
    ptr->prior->next = ptr->next;
    free(ptr);
    return OK;
}
```

# 栈和队列

## 栈

> 栈（Stack）是限定仅在表尾进行插入或删除操作的线性表。因此，对栈来说，表尾端有其特殊含义，称为栈顶（top），相应地，表头端称为栈底（bottom）。不含元素的空表称为空栈

### 定义栈结构体

### 入栈

```c
/**
 * @brief 数据入栈
 * @param[in] S:栈指针, e:入栈元素
 * @return Satus, OK成功, ERROR失败, OVERFLOW其他
 * @note 
 * @warning 
 */
Status Push(SqStack *S, SElemType e){
    if(S == NULL || S->base == NULL){
        return ERROR;
    }
    if(S->top - S->base >= S->stacksize){
        S->base = (SElemType *)realloc(S->base, (S->stacksize + INCREMENTSIZE) * sizeof(SElemType));
        if (S->base == NULL){
            return OVERFLOW;
        }
        S->top = S->base + S->stacksize;
        S->stacksize += INCREMENTSIZE;
    }
    *(S->top++) = e;
    return OK;
}
```



### 出栈

```c
/**
 * @brief 栈顶元素出栈
 * @param[in] S:指向栈的指针, e:接收栈顶元素的指针

 * @note 
 * @warning

Status Pop(SqStack *S, SElemType *e){
    if(S == NULL){
        return ERROR;
    }
    if(S->base == S->top){
        return ERROR;
    }
    *e = *--S->top;
    return OK;
}
```

}

    if(Q.front == Q.rear){
        return ERROR;

    Q->front = (Q->front + 1) % MAXQSIZE;
    return OK;

## 树和二叉树

### 树的定义

树是n个节点的有限集。n=0时称为空树。在任意一颗非空树中：
（1）有且仅有一个特定的称为**根（Root）**的结点
（2）当n>1时，其余结点可分为m(m>0)个互不相交的有限集T1、T2、T3、……Tm，其中每一个集合本身又是一颗树，
并称为根的**子树（SubTree）**。

树的结点包含一个数据元素及若干指向其子树的分支。
结点拥有的子树数称为结点的**度（Degree）**。
度为0的结点称为**叶子（Leaf）**或终端结点；度不为0的结点称为非终端结点或分支结点。
除根结点之外，分支结点也称为内部结点。
树的度是树内各结点的度的最大值。
结点的子树的根称为该结点的孩子（Child），相应的，该结点称为孩子的双亲（Parent）。同一个双亲的孩子之间互称兄弟（Sibling）。
节点的祖先是从根到该结点所经分支上的所有结点。以某结点为根的子树中的任一结点都成为该结点的子孙。

结点的**层次（Level）**从根开始，根为第一层，根的孩子为第二层。双亲在同一层的结点互为堂兄弟，树中结点的最大层次称为树的深度（Depth）或者高度

![树的结构](/../assets/pictures/树的结构.png)

- 有序树: 从逻辑上看，树中结点的各子树从左至右是有次序的，不能互换
- 无序树: 从逻辑上看，树中结点的各子树从左至右是无次序的，可以互换

### 二叉树

二叉树（Binary Tree）是一种每个节点最多有两个子节点的树结构。二叉树是计算机科学中非常基础且重要的树形数据结构，广泛应用于各种算法和数据处理任务中。二叉树的子树有左右之分，其次序不能任意颠倒。

深度为k的，有n个结点的二叉树，当且仅当其每一个结点都与深度为k的满二叉树中的编号从1至n的结点一一对应时，称之为完全二叉树（Complete Binary Tree）。

完全二叉树是一种特殊的二叉树，其定义是：除了最后一层之外，所有层的节点都达到了最大节点数，并且最后一层的节点是从左到右依次排列的。

- 遍历方式

1. 先序遍历(Pre-order): 访问当前根节点->递归遍历左子树->递归遍历右子树

   ```c
   // 先序遍历的递归函数
   void preorderTraversal(BiTNode *root)
   {
       if (root == NULL)
       {
           return; // 如果当前节点为空，直接返回
       }
       // 先访问当前节点
       printf("%c ", root->data);
       // 递归遍历左子树
       preorderTraversal(root->lchild);
       // 递归遍历右子树
       preorderTraversal(root->rchild);
   }
   
   
   //非递归算法
   Status InOrderTraverse(BiTree T)
   {
       SqStack S;
       BiTNode *p;
       InitStack(&S);
       Push(&S, T);
       // 当栈不为空时，循环执行以下操作
       while (!StackEmpty(S))
       {
           // 获取栈顶元素，即当前要处理的节点
           while (GetTop(S, &p))
           {
               // 如果当前节点不为空，将其左子节点压入栈中
               if (p)
                   Push(&S, p->lchild);
               else
                   break;
           }
           // 弹出栈顶元素，即当前处理的节点
           Pop(&S, &p);
           // 如果栈不为空，说明未访问当前节点的右子节点
           if (!StackEmpty(S))
           {
               // 再次弹出栈顶元素，即当前处理的节点
               Pop(&S, &p);
               printf("%c ", p->data);
               // 将当前节点的右子节点压入栈中
               Push(&S, p->rchild);
           }
       }
       return OK;
   }
   
   //先序遍历2
   Status InOrderTraverse2(BiTree T)
   {
       SqStack S;     // 定义一个栈 S，用于存储二叉树的节点。
       BiTNode *p;    // 定义一个指针 p，用于遍历二叉树的节点。
       InitStack(&S); // 初始化栈 S，确保栈为空。
       p = T;         // 将指针 p 指向二叉树的根节点 T，开始遍历。
       // 当当前节点 p 不为空或栈不为空时，继续遍历
       while (p || !StackEmpty(S))
       {
           // 如果当前节点 p 不为空，将节点压入栈
           if (p)
           {
               Push(&S, p);   // 将当前节点压入栈 S 中。
               p = p->lchild; // 移动到当前节点的左子节点，继续向左走。
           }
           else
           {
               Pop(&S, &p);            // 从栈中弹出一个节点，并将其赋值给 p。
               printf("%c ", p->data); // 访问当前节点。
               p = p->rchild;          // 移动到当前节点的右子节点，继续遍历右子树。
           }
       }
       return OK; // 返回 OK，表示遍历完成。
   }
   ```

4. 反转链表核心思想

   > 1. 初始化三个指针：`prev`、`current`、`next`，其中 `prev` 指向 `NULL`，`current` 指向链表的头节点，`next` 用来保存节点的下一个元素。
   > 2. 遍历链表，对于每个节点，先保存 `current` 的下一个节点到 `next` 中。
   > 3. 将当前节点的 `next` 指向 `prev`，然后将 `prev` 移动到当前节点，`current` 移动到 `next`。
   > 4. 重复上述过程直到 `current` 为 `NULL`，即遍历完整个链表。
   > 5. 最后返回 `prev`，即新的头节点。

5. 链表中间插入一个节点

   > 1. 查找链表的中间节点，使用快慢指针方法。快指针每次移动两步，慢指针每次移动一步，直到快指针到达链表末尾，慢指针正好指向中间节点。
   > 2. 创建新节点，并将其插入到中间节点之后。
   > 3. 更新新节点的 `next` 指向原中间节点的 `next`，然后将中间节点的 `next` 指向新节点。


6. 满二叉树和完全二叉树: 

- 满二叉树要求所有非叶子节点必须有两个孩子, 没有度为1的节点, 叶子节点全部都在最底层.

- 完全二叉树要求除最后一层外全部有两个孩子, 最后一层从左至右依次排列.

7. 简述哈夫曼编码的组成过程

   > 创建一个优先队列：
   >
   > 把每个字符及其频率作为一个节点放入优先队列中，优先队列按照频率从小到大排列。
   > 构建哈夫曼树：
   >
   > 从优先队列中取出两个频率最小的节点，创建一个新节点，它的频率是这两个节点频率的和。
   > 这个新节点的两个子节点分别是这两个最小的节点。然后把这个新节点插回优先队列。
   > 重复上述过程，直到队列中只剩下一个节点。这个节点就是哈夫曼树的根节点。
