# C语言编译

主要编译工具 ***GCC（GNU Compiler collection）***

## 编译流程

**Hello.c** -> **预处理器（cpp）： gcc -E** -> **Hello.i** -> **编译器（gcc）：gcc -S** -> **Hello.s** -> **汇编器（as）： gcc -c** -> **Hello.o** -> **链接器（ld）： gcc** -> **可执行文件** 

- 预处理器：cpp	头文件包含、宏替换、条件编译、去掉注释
- 编译器：gcc            C文件编译为汇编文件
- 汇编器：as               汇编文件转换为二进制文件
- 链接器：ld                将多个目标文件和库文件链接成最终的可执行文件

```
gcc -E hello.c -o hello.i
```

# main()函数

main()函数是C语言程序的入口，不管程序有多少代码， 都是从main()函数开始执行。

- main()函数是程序的入口

- main()函数有且只有一个

## C99标准下两种定义方式
```
int main(void) /* 无参数形式 */
{
	...
	return 0;
}

int main( int argc, char *argv[])  /* 带参数形式 */ 
{
	...
	return 0;
}
```

- int argc:  代表调用main函数时的参数数量， 默认是1，如果在调用时有参数传入，值自动增加

- char *argv[]: *argv[]是一个字符串数组， argv[0] 默认是当前程序的名称如**.\hello.exe**, argv[x]是 传入的参数，如调用 **.\hello.exe aa**, 结果如下：

  ```
  argc=2
  argv[0]=.\hello.exe
  argv[1]=aa
  ```

# 头文件

## 文件格式

头文件通过**#include <stdio.h>**引入， 其中定义了变量和函数， 具体的实现是通过同名stdio.c中实现。

- *.c 文件：源文件， 包含程序的主要实现代码，程序的源代码文件
- *.h 文件：头文件，包含函数声明、宏定义、结构体定义、全局变量声明以及其他需要在多个源文件中共享的内容
- **<*>** 尖括号引用的头文件会告诉编译器从标准库中进行查询
- **“*”** 双引号引用的头文件会告诉编译器从自己定义的目录中进行查询

## 文件保护

```
#ifndef MYHEADER_H //如果MYHEADER_H没有定义
#define MYHEADER_H //定义MYHEADER_H
//头文件内容
#endif 		//结束头文件保护
```

# 代码风格和注释

## 代码风格

- 代码块保持整洁， 用4个空格或者Tab键

- 变量命名尽量带有具体含义， 能明确表达变量的功能

- 代码中尽量避免2，3等常量， 采用宏定义代替
  ```
  define MAX_COUNT 5
  ```

- 换行尽量保持括号内对其如：

  ```
  int test(int num1, int num2, int num3, int num4, int num5
           int num6, int num7)
  ```

## 代码注释

- 多行注释

  ```
  /* 
  aaaa
  bbbb
  */
  ```

​	内部不能嵌套多行注释符号

- 单行注释

  ```
  // aaaa
  ```



# 错误记录：

1. C语言代码中有未定义的函数， 编译器会在链接阶段进行报错， 在链接阶段，编译器会将编译后的目标文件与库文件、其他目标文件进行链接。如果存在函数的调用，但是没有对应的函数定义（或者在链接的文件中找不到定义），链接器会报告一个“未定义引用”错误。这时，编译器才能检测出是否有未定义的函数。编译阶段：在这个阶段，编译器会将源代码转换成目标代码（即机器码）。此时，编译器会检查语法错误、类型错误等，但它通常不会检查是否有未定义的函数。只要函数已被声明或者其定义可以在某个地方找到，编译器就会继续生成目标代码。

2. C语言中的非执行语句如注释、宏定义等不会被转换成机器指令，只在编译时起作用， 不会影响生成的机器代码

3. main函数可以写成如下格式， **void main()**在标准C中不被推荐

   ``` 
   int main()
   int main(void)
   int main(int argc, char *argv[])
   ```

4. C 语言中， **#include **指令的使用方式唯一区别是**<>**和**""**的区别， **<>**会优先查找标准库，**“”**会优先查找当前目录

5. 头文件用于共享函数、宏定义以及外部库函数， 全局变量一般不放在头文件中
