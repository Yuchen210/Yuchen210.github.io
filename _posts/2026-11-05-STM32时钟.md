# STM32F407 时钟控制器 RCC（4‑1）

## 1 时钟基础概念

时钟相当于嵌入式系统的**统一节拍器**，所有寄存器、外设、CPU 都按照时钟节拍工作。

- **频率**：1 秒内电平跳变的总次数，单位 `Hz`
- **周期**：完成一次高低电平变换的时间，`周期 = 1 / 频率`

> 示例：8MHz 时钟，周期 = 1 / 8 000 000 = **125ns**。

## 2 振荡器分类

### RC 振荡器

- 原理：电阻电容充放电产生振荡。
- ✅优点：成本低、启动速度快
- ❌缺点：**精度差**，受温度、电压影响大
- STM32 内部 HSI、LSI 属于 RC 振荡器。

### 无源晶体振荡器（无源晶振）

- 利用**压电效应 + 共振**工作；芯片内部提供振荡反相放大器，晶振本身不能独立起振。
- 外部需要搭配负载电容 `CL1、CL2`。
- STM32 的 HSE（8MHz）、LSE（32.768KHz）常用无源晶振。

### 有源晶体振荡器（有源晶振）

- 内部集成完整振荡电路，**需要外部供电**，输出稳定时钟信号。
- STM32 的 HSE 支持配置`HSEBYP`旁路模式，直接输入有源晶振时钟。

## 3 STM32F407 四大基础时钟源

表格

| 时钟源  | 类型             | 频率       | 说明                                                         |
| ------- | ---------------- | ---------- | ------------------------------------------------------------ |
| **HSI** | 内部 RC 高速时钟 | 16 MHz     | 无需外部器件；启动快；精度一般；可直接做系统时钟或 PLL 输入  |
| **HSE** | 外部高速时钟     | 4‑26 MHz   | 无源 / 有源晶振；精度高；开发板常用 8MHz；可直接做系统时钟或 PLL 输入 |
| **LSI** | 内部 RC 低速时钟 | 32 kHz     | 低功耗；供独立看门狗 IWDG、RTC；精度差                       |
| **LSE** | 外部低速晶振     | 32.768 kHz | 无源晶振；精度高，专门给 RTC 实时时钟                        |

> LSE 32.768KHz：`2^15 = 32768`，分频后刚好得到 1 秒，专门用于日历计时。

## 4 PLL 锁相环（主 PLL）

PLL 作用：对输入时钟**分频‑倍频‑再分频**，得到高频系统时钟 SYSCLK。

输入来源二选一：`HSI` 或者 `HSE`。

公式： \(f_{VCO}=f_{in} \times \frac{N}{M}\) \(SYSCLK = f_{VCO} / P\) \(f_{PLLQ}=f_{VCO} / Q\)

- M：预分频器，输入时钟先除以 M；**M 取值范围 2‑63**
- N：倍频因子，VCO 倍频；**N 取值 50‑432**
- P：系统时钟输出分频，可选 /2, /4, /6, /8；最终生成 SYSCLK，F4 最大 168MHz
- Q：USB 等外设分频输出，Q 取值 4‑15

> 开发板典型配置：HSE=8MHz，M=8，N=336，P=2，Q=7
>
> \(f_{VCO}=8 \times \frac{336}{8}=336\,\text{MHz}\) \(SYSCLK = 336 / 2 = \mathbf{168\,MHz}\) \(f_{PLLQ}=336 /7 =48\,\text{MHz（USB需要48M）}\)

## 5 系统时钟树层级（SYSCLK → HCLK → PCLK1 / PCLK2）

1. **SYSCLK**：系统内核时钟。 多路选择器可选择三种来源：`HSI` / `HSE` / `PLLCLK`。最大 168MHz。

2. HCLK（AHB 总线时钟）

   SYSCLK 经过 AHB 预分频器得到 HCLK。

   - 供给：AHB 总线内核、DMA、存储器、Cortex‑M4 内核 FCLK、SysTick。
   - F4 最大 HCLK = **168MHz**。

3. **PCLK1（APB1 外设时钟）** HCLK 经过 APB1 预分频输出 PCLK1。

   > 硬件特性：**当 APB1 预分频器分频系数 > 1 时，定时器时钟会自动 ×2 倍**。

   - APB1 最大外设时钟 **42MHz**；定时器最大可达 84MHz。

4. **PCLK2（APB2 外设时钟）** HCLK 经过 APB2 预分频输出 PCLK2。

   > 硬件特性：**当 APB2 预分频器分频系数 > 1 时，定时器时钟自动 ×2 倍**。

   - APB2 最大外设时钟 **84MHz**；定时器最大可达 168MHz。

> 标准 168M 配置示例：
>
> - SYSCLK = 168 MHz
> - AHB 预分频 = 1 → HCLK = 168 MHz
> - APB1 预分频 = 4 → PCLK1 = 42 MHz，APB1 定时器时钟 = 84 MHz
> - APB2 预分频 = 2 → PCLK2 = 84 MHz，APB2 定时器时钟 = 168 MHz

### 总线挂载外设简单区分

- **AHB**：GPIO、DMA、ETH、FSMC 等高速外设
- **APB1**：I2C、SPI2/3、USART2‑5、定时器 2‑7、12‑14、DAC（低速外设，最高 42M）
- **APB2**：SPI1、USART1‑6、定时器 1、8‑11、ADC（高速外设，最高 84M）

## 6 RTC 与 IWDG 时钟

1. RTC 实时时钟

   时钟源三选一：

   - LSE（推荐，高精度）
   - LSI（精度差，不适合计时）
   - HSE 经过硬件分频输入 RTC

2. **IWDG 独立看门狗** 时钟源固定只有 **LSI（32kHz）**，即使主系统时钟失效看门狗依旧可以工作。

## 7 MCO 时钟输出引脚

MCO：Microcontroller Clock Output，微控制器时钟输出，可以把内部时钟输出到芯片引脚，用于测量或者给外部芯片提供时钟。

表格

| 引脚 | 名称 | 可选时钟源                     |
| ---- | ---- | ------------------------------ |
| PA8  | MCO1 | LSE、HSE、HSI、PLLCLK          |
| PC9  | MCO2 | SYSCLK、PLLI2SCLK、HSE、PLLCLK |

MCO 内部自带分频器（1‑16 分频）输出到引脚，可以用示波器测量实际芯片内部时钟。

## 8 RCC 编程配置要点

1. 开启 HSE，等待 HSE 稳定就绪标志位`HSERDY`。
2. 配置 PLL 的 M/N/P/Q 参数，选择 PLL 输入源（HSE 或 HSI）。
3. 使能 PLL，等待`PLLRDY`就绪。
4. 设置 AHB、APB1、APB2 分频系数。
5. 切换系统时钟源为 PLLCLK，读取`SWS`位确认切换完成。
6. 打开各个外设对应的 AHBEN / APB1EN / APB2EN 时钟使能位。

> 注意：外设**必须打开时钟使能寄存器，模块才上电工作**，否则寄存器读写无效。

## 9 时钟故障检测 CSS

HSE 时钟安全系统 CSS：

- 一旦检测 HSE 晶振停振，硬件自动切换系统时钟到 HSI，同时产生时钟失效中断，防止死机。
