# 条件判断结构

## if结构

if 语句用于根据一个条件是否为真，决定是否执行代码块

```c
if (condition) {
// 如果 condition 为真，执行这段代码
}
//condition为非0值代表真
```

## if-else结构

if-else 语句为条件提供了一个 else 分支，当 if 条件为假时执行 else 的代码块。

```c
if (condition) {
// 如果 condition 为真，执行这段代码
} else {
// 如果 condition 为假，执行这段代码
}
```

## if-else if结构

else if 允许你检查多个条件。当一个条件成立时，后续条件将不会再被检查。

```c
if (condition1) {
// 如果 condition1 为真，执行这段代码
} else if (condition2) {
// 如果 condition2 为真，执行这段代码
} else {
// 如果前面所有条件都为假，执行这段代码
}
```

## switch-case结构

switch 语句用于处理基于某个表达式值的多分支选择，通常适用于枚举或固定值的选择。

```c
switch (expression) {
case value1:
// 当 expression 等于 value1 时执行
break;
case value2:
// 当 expression 等于 value2 时执行
break;
// 可以有多个 case 分支
default:
// 如果没有匹配任何 case，执行 default 代码
}

//如果没有命中任何case, 执行default,如果没有default, 什么都不做
//如果switch匹配到对应的case后, 当前case没有break语句, 那么就会继续执行后续的所有case, 直到遇到break或default执行完毕
```

# 循环结构

## for循环结构

```c
for(初始化;条件;迭代)
{
    //循环体
}
```

- 初始化：用于设置循环的初始条件

- 条件判断：每次迭代前检查，决定是否继续执行循环

- 迭代操作：在每次循环结束后更新循环变量

- 省略部分for语句

  ```c
  inti=0;
  for(;i<5;)
  {
      printf("%d\n",i++);
  }
  ```

- 当在 for 循环中遇到 break 语句时，循环会立即终止，程序控制权跳转到循环之后的代码，无需等待循环条件为假。

  ```c
  for(初始化表达式;条件表达式;更新表达式)
  {
      //执行一些代码
      if(某个条件)
      {
          break;//满足某个条件时终止循环
      }
      //其他代码
  }
  ```

  

## while循环结构

假设有一个程序需要在满足某个条件的前提下，反复执行一段代码，直到条件变为假。

```c
while(条件表达式)
{
    //循环体
}
```

- 在C语言中，while 循环与 break 语句的结合使用非常常见。break 语句用于立即退出当前循环，不管循环条件是否满足，一旦执行到 break，循环就会立刻终止，并跳到循环后的代码。

  ```c
  while(条件表达式)
  {
      //执行一些代码
      if(某个条件)
      {
          break;//立即终止循环
      }
      //其他代码
  }
  ```

- continue 语句用于跳过本次循环的剩余部分，并立即开始下一次循环迭代。它只影响当前循环的执行流程，不会终止循环。

  ```c
  while(condition)
  {
      //循环体
      if(skip_condition)
      {
          continue;//跳过当前循环，继续下一次迭代
      }
      //其他操作
  }
  ```

- while循环最常用于不确定循环次数的场景。例如，用户输入某些数据，直到输入满足某个条件为止。

- 在某些实时系统或交互式程序中，while循环可以用于持续检测某个事件是否发生，比如网络连接是否建立、文件是否准备就绪等。

  ```c
  while(NFC_configuresWiFiNetwork(ndefBuff)!=WIFI_SUCCESS{
      printf("nfcconnectwifiisfailed!\r\n");
      oled_consle_log("wifino.");
      sleep(1);
      SSD1306_CLS();//清屏
  }
  ```

- 当一个任务需要根据某个条件重复执行时，while循环是非常好的选择。例如，模拟一个简单的倒计时功能，直到倒计时结束

  ```c
  int countdown=10;
  while(countdown>0){
      printf("倒计时：%d\n",countdown);
      countdown--;
  }
  printf("倒计时结束！\n");
  ```

## do while循环结构

先执行一次循环体：无论条件是否为真，循环体会至少执行一次。检查条件：在第一次执行循环体后，才会检查while中的条件。循环结束或继续：如果条件为真，继续执行循环体；如果为假，跳出循环。

```
do{
// 循环体
}while(条件);
```

- while 循环：先判断条件，只有条件为真时才执行循环体。
  do-while 循环：先执行循环体，再判断条件。

```c
// while 循环
inti= 1;
while(i> 1) {
printf("This will never print\n");
}

// do-while 循环
i= 1;
do{
printf("This will print once\n");
} while(i> 1);
```

- 结合 if-else：在循环体内使用条件判断，控制循环的行为。
  结合 break和 continue：
  break：立即终止循环。
  continue：跳过当前循环迭代，继续下次迭代。

```c
inti= 1;
do{
	if(i== 3) {
		i++;
		continue;// 跳过 i== 3 的情况
	}
	printf("%d ", i);
	i++;
}while(i<= 5);
// 输出：1 2 4 5
```
