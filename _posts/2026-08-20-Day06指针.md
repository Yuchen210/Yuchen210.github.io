# 指针

指针是一个变量，它存储另一个变量的内存地址。变量存储在内存中，每个变量占据一定的内存空间，并有唯一的地址。指针就是用来存储这些地址的变量

```c
声明指针：
    int*p;	// 声明一个指向 int 类型的指针 p,用于定义指针，表示这是一个存储地址的变量。
赋值与获取地址：
    int a = 5;
	p = &a;	// 将 a 的地址赋给指针 p
解引用（dereferencing）：通过指针访问变量值。
    int value = *p;	// 通过解引用访问指针 p 指向的变量 a 的值
```

- 算数运算

  - 指针加法:

  ```c
  当对指针进行加法运算时，指针会移动到它所指向类型的下一个元素位置。加法运算的步长取决于指针所指向数据类型的大小。
  例如：
  	int arr[5] = {1, 2, 3, 4, 5};
  	int *p = arr; // p 指向 arr[0]
  	// 指针加法
  	p++; // p 指向 arr[1]，即 &arr[1]
  这里，p++ 实际上将 p 移动了 sizeof(int) 个字节，因为 p 指向的是 int 类型的数组元素。
  ```

  - 指针减法:

  ```c
  类似地，指针减法会将指针向数组的前一个元素移动。
  	p--; // p 现在又指向 arr[0]
  ```

  - 指针相减:

  ```c
  如果两个指针指向同一个数组中的元素，则它们的差值表示两个元素之间的距离（以元素为单位，而不是字节为单位）。
      int arr[5] = {1, 2, 3, 4, 5};
  	int *p1 = &arr[3]; // 指向 arr[3]
  	int *p2 = &arr[0]; // 指向 arr[0]int diff = p1 -p2; // diff = 3，表示两个元素之间有 3 个 int 的距离
  指针相减的结果是两个指针之间的元素个数，而不是字节差。
  ```

  - 指针于整数相加/减

  ```c
  指针加上一个整数时，会将指针移动若干个元素的位置。例如：
      p = p + 2; // p 移动两个元素
  与加法类似，指针减去一个整数时，会将指针移动到前面的元素。例如：
      p = p -1; // p 向前移动一个元素
  ```

  - 指针的比较运算

  > 指针可以进行比较运算，用来判断两个指针是否指向相同位置或不同位置。
  > 指针的比较运算包括：
  >
  > ==：判断两个指针是否指向相同位置。
  > !=：判断两个指针是否指向不同位置。
  > <、>、<=、>=：比较两个指针在内存中的相对位置。这些运算仅在指针指向同一个数组时有意义。

# 指针常量与常量指针

指针常量是常量, 指针指向一个常量

常量指针是指针, 这个指针是一个常量

| 特性               | 常量指针const int *p | 指针常量int * const p        |
| ------------------ | -------------------- | ---------------------------- |
| 能否修改指向的数据 | 不可以               | 可以                         |
| 能否修改指针的指向 | 可以                 | 不可以                       |
| 修饰对象           | 被指向的数据         | 指针本身                     |
| 典型用途           | 防止函数误改数据     | 固定指针的指向地址(硬件地址) |

常量指针常量:

const int * const p: 既不可修改指向也不可修改值

# 指针数组与数组指针

指针数组是数组, 数组里存放的是指针

数组指针是指针, 这个指针指向一个数组

- 一维数组与指针的关系：数组名是一个指针常量，指向数组的第一个元素。

```c
int arr[3] = {1, 2, 3};
int *p = arr; // 指向数组的第一个元素printf("第一个元素: %d\n", *p); // 访问第一个元素
printf("第二个元素: %d\n", *(p + 1)); // 访问第二个元素
```

## 指针数组:

> 指针数组（Array of Pointers）是 C 语言中一种数据结构，指的是一个数组，其元素是指针。每个数组元素都可以存储一个指针，这些指针通常指向其他数据类型的变量或内存块。指针数组可以非常灵活地应用于多种场景，如字符串数组、动态内存管理、函数指针数组等

```c
int *arr[5]; // 一个包含 5 个指向 int 类型数据的指针数组
arr是一个数组，包含 5 个元素，每个元素都是一个 int * 类型的指针。即 arr中的每个元素都可以存储一个指向 int 类型变量的地址。
```

```c
//访问和使用
int a = 10, b = 20;
int *arr[2]; // 指针数组，包含 2 个元素
arr[0] = &a; // 第一个元素指向 a 的地址
arr[1] = &b; // 第二个元素指向 b 的地址
printf("arr[0] 指向的值: %d\n", *arr[0]); // 输出 10
printf("arr[1] 指向的值: %d\n", *arr[1]); // 输出 20
```

## 数组指针:

> 数组指针是一个指针，它指向一个完整的数组，而不是数组中的单个元素
> int *p;：普通指针，指向一个int变量。
> int *p[5];：指针数组，每个元素是一个指针。
> int (*p)[5];：数组指针，指向一个包含5个int元素的数组。

1. 数组名的两种身份

```c
intarr[5] = {10,20,30,40,50};
在大多数表达式中：arr退化成int*，指向arr[0]。例如：
arr== &arr[0] // 值相等，类型都是 int*
在特殊场景（如sizeof,&运算）下：arr保持数组类型int[5]，不会退化。
```

2. &arr到底是什么

> 如果你不知道“退化”这个规则，就很容易误解：既然arr是首地址，那&arr就是“首地址的地址”？但理解了退化后，你会发现事实并不是这样：
> arr在这里没有退化，仍然是一个5 个 int 的数组对象。
> &arr就是“取这个数组对象的地址”。
> 所以：
> arr→ 在表达式中通常退化成 int\*，指向 arr[0]
> &arr→ 指向整个数组的指针，类型是 int(*)[5]

## 数组指针与二维数组

# 指针函数与函数指针

指针函数是函数, 返回类型为指针的函数

函数指针是指针, 这个指针指向一个函数

## 指针函数

> 返回类型为指针的函数, 换句话说，函数返回一个指针。指针函数和普通函数的区别主要在于其返回值是指针

```c
int* getMax(int* a, int* b) {
	if(*a > *b)
		return	a;
	else
		return	b;
}
int main() {
	int x = 10, y = 20;
	int *max = getMax(&x, &y);// 调用返回指针的函数
	printf("Max: %d\n", *max);// 解引用指针，输出较大的值
	return 0;
}
```

## 函数指针

> 指向函数的指针。函数指针可以存储函数的地址，从而通过指针来调用该函数。函数指针在实现回调函数、动态选择函数或函数数组时非常有用

```c
int add(int a, int b) {
	return a + b;
}
int multiply(int a, int b) {
	return a * b;
}
int main() {
// 声明一个函数指针
	int (*func_ptr)(int, int);// 让函数指针指向 add 函数
	func_ptr = add;
	printf("Add: %d\n", func_ptr(3, 4));// 调用 add 函数，输出 7 // 让函数指针指向 multiply 函数
	func_ptr= multiply;
	printf("Multiply: %d\n", func_ptr(3, 4));// 调用 multiply 函数，输出 12 return0;
}
```

## 函数指针作为函数参数

> 函数指针可以作为函数的参数，这通常用于实现回调函数或策略模式，在排序、搜索等操作中也非常常见

```c
// 定义两个函数
int add(inta, intb)
{
    return a + b;
}
int subtract(inta, intb)
{
    return a - b;
} 
// 定义一个接收函数指针的函数
int compute(int (*operation)(int, int), int x, int y)
{
    return operation(x, y); // 通过函数指针调用函数
}
int main()
{
    // 传递 add 和 subtract 函数作为参数
    printf("Add: %d\n", compute(add, 10, 5));           // 输出 15
    printf("Subtract: %d\n", compute(subtract, 10, 5)); // 输出 5 return0;
}
```

## 函数指针数组

> 函数指针可以存储在数组中，用于处理多个函数，尤其在实现命令表或分支逻辑时非常方便。

```c
// 定义两个函数
int add(int a, int b)
{
    return a + b;
}
int multiply(int a, int b)
{
    return a *b;
}
int main()
{
    // 定义函数指针数组
    int (*operations[2])(int, int);
    operations[0] = add;
    operations[1] = multiply;                      // 调用函数指针数组中的函数
    printf("Add: %d\n", operations[0](5, 3));      // 输出 8
    printf("Multiply: %d\n", operations[1](5, 3)); // 输出 15 return0;
}
```

# 二级指针

- 基本概念

> 指针的指针简单来说就是一个存储另一个指针地址的变量。假设我们有一个普通的指针，它指向某个变量的内存地址。一个指针的指针则指向这个指针的地址，从而形成一种多级引用关系。

```c
int a = 10;// 普通变量
int *p = &a;// 指针 p 指向变量 a 的地址
int **pp = &p;// 指针的指针 pp 指向指针 p 的地址
```

- 应用场景

> 1. 动态内存分配
>
> ```c
> // 动态分配一个指针的指针，存储每一行的地址
> int **array = (int **)malloc(rows * sizeof(int *));
> if (array == NULL)
> {
>     printf("内存分配失败！\n");
>     return 1;
> }
> // 为每一行分配内存，存储列元素
> for (inti = 0; i < rows; i++)
> {
>     array[i] = (int *)malloc(cols * sizeof(int));
>     if (array[i] == NULL)
>     {
>         printf("内存分配失败！\n");
>         return 1;
>     }
> }
> ```
>
> 2. 函数参数传递
>
> ```c
> void allocateMemory(int **ptr)
> {
>     *ptr = (int *)malloc(sizeof(int)); // 动态分配内存
>     if (*ptr != NULL)
>     {
>         **ptr = 100; // 给分配的内存赋值
>     }
> }
> int main()
> {
>     int *p = NULL; // 调用函数，通过指针的指针分配内存
>     allocateMemory(&p);
>     if (p != NULL)
>     {
>         printf("p 指向的值: %d\n", *p); // 输出: 100
>         free(p);                        // 释放内存
>     }
>     return 0;
> }
> ```

# 野指针

## 悬挂指针

- 函数运行结束后, 局部变量的空间已经释放, 存储局部变量的指针值并没有被清空, 因此指针还指向局部变量的地址

## 野指针

> 野指针（Dangling Pointer）是指向无效内存地址的指针。它的产生通常是由于指针指向的内存已经被释放、未正确初始化或超过其作用域。野指针的使用会导致未定义行为，包括程序崩溃、内存泄漏甚至安全漏洞（如缓冲区溢出、代码注入等），因此在编程中应尽量避免它们

- 指针未初始化
- 指向的内存已被释放
- 超出变量的作用域
- 多次释放同一块内存

## 规避方法

- 指针初始化为NULL
- 释放指针后置为NULL
- 避免重复释放内存
- 调试工具检测内存问题

## 文件操作

- fputc函数

把一个字符写到磁盘文件上去。其调用的一般形式为：fputc(ch,fp);

- fgetc函数

从指定的文件读入一个字符，该文件必须是以读或读写方式打开的。其调用的一般形式为：ch= fgetc(fp);

- fgets函数

fgets，从指定的文件中读一个字符串到字符数组中
fgets(字符数组名, n, 文件指针);
其中的n是一个正整数。表示从文件中读出的字符串不超过n-1个字符。在读入的最后一个字符后加上串结束标志'\0'。
fgets(str, n, fp);

- fputs函数

向指定的文件写入一个字符串
fputs(字符串， 文件指针);
其中字符串可以是字符串常量，也可以是字符数组名，或指针变量。
fputs("abcd", fp);

- fprintf函数和fscanf函数

```c

```

## 读写数据块

```c
读数据块函数：
	fread(buffer, size, count, fp);
写数据块函数：
    fwrite(buffer, size, count, fp);
其中，buffer 是一个指针，在fread函数中，它表示存放输入数据的首地址。在fwrite函数中，它表示存放输出数据的首地址；
size表示数据块的字节数；
count表示要读写的数据块块数；
fp表示文件指针。
	fread(fa, 4, 5, fp);
```

## 文件定位

```c
rewind 函数，将文件内部的位置指针移动到文件首。形式为：
    rewind(文件指针);
fseek 函数，移动文件内部位置指针，形式为：
    fseek(文件指针, 位移量, 起始点);
“位移量"表示移动的字节数，要求位移量是long型数据，以便在文件长度大于64KB时不会出错。当用常量表示位移量时，要求加后缀”L”。
fseek(fp, 100L, 0);
```
