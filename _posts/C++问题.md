1 什么是引用？特点？

引用的本质是对象的别名, 不会开辟新的内存空间, 必须在定义时完成初始化, 初始化完成后不可更改, 在进行传递时可以减少内存拷贝的开销, 

2 引用和指针的区别？

| 对比维度     | 指针（`T*`）                                                 | 引用（`T&`）                                                 |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 定义本质     | 独立变量，存储目标内存地址，本身占用内存                     | 目标变量的别名，**不额外开辟内存**（编译器底层大多还是用指针实现，但语法层面是别名） |
| 初始化       | 定义时可选不初始化；可初始化为`nullptr`                      | **必须定义时初始化**，绑定一个有效对象，不能绑定空           |
| 是否可空     | 可以是`nullptr`，指向空                                      | **不能是空引用**，引用一定绑定有效实体                       |
| 能否改指向   | 可以随时修改，指向不同对象                                   | **一旦绑定，不能更换绑定对象**，只能修改绑定对象的值         |
| 使用语法     | 解引用`*p`，访问成员`p->mem`                                 | 直接使用名字，访问成员`ref.mem`                              |
| 多级支持     | 支持多级指针 `T**`                                           | **没有多级引用 `T&&`不是二级引用，是右值引用**               |
| 作为函数参数 | 传地址，可以修改实参；可以传 null                            | 传别名，可以修改实参；传入必须是有效变量                     |
| 作为返回值   | 可以返回指针（注意不要返回局部变量地址）                     | 可以返回引用（注意不要返回局部变量引用，UB）                 |
| sizeof       | `sizeof(指针)` 得到指针本身大小（32 位 4 字节 /64 位 8 字节） | `sizeof(引用)` = **所绑定对象的大小**                        |
| 自增运算     | `p++`：指针向后偏移，移动指向                                | `ref++`：对象本身自增，不是移动绑定                          |
| 野值风险     | 容易出现野指针、空指针                                       | 只要合法定义，不会有空引用；但**引用绑定已经销毁对象，依然是 UB（悬垂引用）** |

3 什么是函数重载？它的作用是什么？

函数重载是指函数名称相同, 函数的参数不同(参数类型, 参数个数和参数顺序), 编译器在编译阶段给函数唯一名称, 根据调用确定使用那一个函数.

针对语义相近的功能, 复用同一个函数名, 方便调用, 使用者不用记忆一堆不同函数名, 静态多态的一种实现方式

4 函数重载在底层是如何实现的？

底层依赖编译器给函数取别名, 参数类型的函数编译器在编译后会有不同类型的名称, 比如_Z4funci

5 什么是默认参数？它有什么作用？

默认参数也称为缺省参数, 是指在函数声明或定义时为某些参数指定默认值, 这样在调用时如果未提供相应的实参则自动使用这些预设的默认值.

6 默认参数的设置规则是什么？

一旦某个参数设置了默认值, 它右侧的所有参数也必须有默认值

7 new/delete运算符的作用是什么？

new: 为对象动态分配一块内存空间, 并实例化对象

delete: 销毁new分配的对象并释放其对应的内存空间

8 new/delete运算符与malloc/free的区别是什么？

| 对比项          | new / delete                    | malloc / free                     |
| --------------- | ------------------------------- | --------------------------------- |
| 语言属性        | C++ 运算符                      | C 库函数                          |
| 调用构造 / 析构 | new 调用构造，delete 调用析构   | 只管理裸内存                      |
| 返回值          | 对应类型指针，无需强转          | void*，C++ 必须强转               |
| 失败处理        | 默认抛 `bad_alloc` 异常         | 返回 NULL                         |
| 大小参数        | 自动计算类型大小                | 手动传入字节数                    |
| 重载            | 支持重载 operator new /delete   | 不可重载                          |
| 数组            | new [] /delete []，记录对象数量 | malloc 只分配一块连续内存，无计数 |
| 内存位置        | 堆，底层依赖 malloc             | 堆                                |

9 命名空间的作用是什么？

命名空间可以防止命名冲突, 划分更加精细的逻辑单元, 提高代码的可读性和维护性

10 如何定义和使用命名空间？

C++中通过namespace关键字来定义命名空间.

通过using namespace关键字来使用命名空间, 也可以直接使用命名空间::名称来直接使用

11 封装 继承 多态分别是什么？

封装: 将一类具有相同属性和行为的事物抽象成一个类, 将数据和操作数据的方法组合在一起, 形成一个独立的单元.

继承: 允许一个类继承另一个类的属性和方法, 子类可以复用父类的代码, 减少代码重复, 同时也可以定义自生的属性和方法

多态: 多态分为静态多态和动态多态. 函数重载, 模版编程等可以称之为静态多态. 动态多态依赖于类的继承, 父类中定义虚函数, 子类中重写父类的虚函数, 使用父类指针或引用管理子类.

12  什么是类？类和结构体的区别？

类时将数据和操作数据行为的方法封装起来, 并对这些数据和方法加以访问权限控制的单元.

类和结构体相比, 结构体默认继承方式为public, 类的默认继承方式为private

13 什么是对象？

对象是指类通过构造函数, 对类中的属性和成员分配内存空间, 并对其赋值之后所实例化出的产物

14 构造函数的作用？特点？

构造函数构建对象的基本状态, 用于申请资源, 完成成员变量初始化工作.
名字与类名相同, 没有返回值类型, 可以被重载

15 构造函数的分类？

默认构造函数, 有参构造函数, 拷贝构造函数

16 析构函数的作用？

析构函数是用来释放对象占用的资源, 确保程序的安全性和稳定性,
名字与类名相同, 前面加~, 没有返回值, 也不接受任何参数, 每个类只能有一个析构函数, 不能重载

17 什么是友元？特点？

通过friend关键字将函数或类声明为自身的友元, 友元函数和友元类能够访问本类中所有权限的成员, 能够破坏类的封装性, 使用时需要慎重

主要是用于特定场景下提高灵活性, 友元关系是单向的, 不具有交换性, 传递性和继承性

18 什么是运算符重载？

运算符重载是指自定义类型重新定义亦有的运算符的行为, 是其能够操作自定义类型的对象, 使代码更加直观简洁, 提升代码的可读性

19 c++中static的作用？

静态修饰符, 修饰普通变量和函数与C语言一样, 修饰类成员代表该成员属于类本身而不是某个具体对象

静态成员属于类本身, 不属于具体对象, 对于不需要每隔对象都独立保存的信息, 可以使用静态成员, 可以在不创建类的实例的情况下直接通过类名调用

20 C++中有哪些继承方式？它们对成员访问权限的影响是什么？

public继承: 父类中的public和protected成员继承权限不变, 子类无法使用父类private成员

protected继承: 父类中的public和protected成员继承权限为protected, 子类无法使用父类private成员

private继承: 父类中所有权限成员变为private, 子类无法使用父类private成员

21 什么是多层继承？什么是多重继承？

多层继承: 链式继承, 每个子类只继承一个直接父类, 单通过多层继承关系, 可以间接访问更上层基类的成员

多重继承: 每个子类同时继承多个父类的属性和方法

22  c++的动态多态性是什么实现的？

动态多态是通过虚函数和vbptr和vtable实现的, 通过基类指针/引用调用虚函数, 根据指针实际值向虚函数表中的的值决定具体调用那个版本的函数

23  实现C++的动态多态性需要具备哪些条件？

动态多态性依赖于继承关系, 父类中有虚函数, 子类中重写了虚函数, 使用父类指针或引用访问子类对象

24  为什么要把基类中的析构函数设计成虚析构函数？

如果不涉及为虚析构函数, 在多态发生时, 释放父类指针的时候, 由于父类的析构函数为普通的虚构函数, 编译器会直接调用父类的析构函数, 而不会去调用子类的析构函数, 导致内存泄露. 

如果父类析构函数为虚析构函数, 编译器在调用时会自动调用子类的析构函数, 然后再调用父类自己的析构函数.
