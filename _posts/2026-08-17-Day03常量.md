# 字面常量

字面常量是指直接出现在代码中的固定值, 在程序运行期间保持不变, 没有符号名, 直接以值的形式存在, 通常存储在常量区或只读数据区, 意味着他们是不可修改的, 如果程序试图修改这些字符串, 可能会导致运行时错误(通常是段错误)

## 整数常量

- 十进制整数: 不带前缀的整数, 如 10, -43, 1000
- 八进制整数: 以0开头表示, 如012
- 十六进制整数: 以0x或0X开头表示, 如0xA

### 后缀修饰符

- u或U: 表示无符号整数
- l或L: 表示长整型
- ll或LL: 表示长长整型

## 字符串常量

双引号括起来的一系列字符, C语言中以空字符'\0'结束

```c
char str[] = "Hello, world!"; //字符串常量
```

- 字符串常量中的每一个字符都被存储为字符数组的一个元素, 最后一个字符是'\0', 表示字符串结束.

# 符号常量

符号常量是通过符号名定义的常量。符号常量可以用** #define** 预处理指令或者 **const** 关键字定义。

## #define定义符号常量

- 定义: #define 是 C 语言的预处理指令，用来定义符号常量或宏。预处理器会在编译时将符号常量替换为定义的值。

- 语法: #define 常量名 常量值
- 特点: #define 是简单的文本替换，不占用内存。无类型检查，因此不具备类型安全性。

## const定义符号常量

- 定义：const 关键字用于定义具有类型的符号常量。使用 const 修饰的变量不能被修改。
- 语法：const 数据类型 常量名 = 常量值;
- 特点：const 常量有类型限制，编译器会进行类型检查。const 常量存储在内存中，可以参与程序运行时的计算。

# 枚举常量

枚举类型中的枚举成员是整数常量, 枚举类型允许定义一组命名的整数常量, 通常用于表示一组相关的选项或状态

```c
enum Color{
    RED = 1;
    GREEN;
    BLUE;
}; //定义一组枚举常量
```

# 常量的作用

- 定义不可变的值: 常量可以用来表示在程序中永远不会改变的数值，如数学常量、物理常量等。这些数值一旦定义，就不会在程序的执行过程中发生改变。例如，PI（圆周率）就是一个典型的数学常量。
- 提高代码的可读性: 使用常量可以使代码更加易读和可理解。例如，使用常量代替魔法数字（magic number），让代码的含义更加明确。

- 便于维护和修改: 常量使得程序更加易于维护。如果程序中有多个地方使用同一个固定值，使用常量可以很容易地对其进行全局修改，而不需要修改多个地方。
- 防止意外修改: 常量可以用于保护那些不应该在程序运行过程中被改变的变量。通过 const关键字定义的常量可以防止意外的赋值或修改，确保程序的行为符合预期。

# const  static #define

## const、static和#define

### const

- 只读, 不能修改, 控制读写权限
- 修饰变量: 初始化后不可赋值修改
- 修饰函数参数: 函数内不能修改该参数
- 修饰函数C++: 成员函数内不能修改成员变量

### static

- 限制变量存储位置, 活多久, 哪里能访问, 属于谁
- 全局变量\全局函数: 作用域限制当前文件内
- 函数内局部变量: 生命周期变为全程序, 只初始化一次, 变量值不丢失
- C++类成员:  不属于对象, 属于类, 所有对象共享

### #define

- 宏定义， 预处理阶段机械的执行字符串替换， 没有类型检查， 不分配内存空间

## const int a 和 int const a的区别

### 普通变量

完全等价, 没有任何区别, const修饰紧跟它的类型

const int <-> int const

### 指针场景

- const int *p: 

  > 等价于 int const *p, 指向常量的指针, 指针本身可以修改, 不能通过指针修改指向的值

```c
int x = 1, y = 2;
const int *p = &x;
p = &y;    // ✅ 允许，指针可以换指向
*p = 100;  // ❌ 禁止修改内容
```

- int * const p:

  > 常量指针, 指针本身不能修改指向, 可以修改指向的值

```c
int x = 1,y=2;
int * const p = &x;
p = &y;    // ❌ 指针不能改指向
*p = 100;  // ✅ 可以修改内容
```

## const和define的区别

- 预处理器宏与变量的区别

  > #define 是一个预处理器指令，用于在编译前将某些文本替换为指定的值。它没有类型信息，是简单的文本替换。#define 声明的常量不会占用内存，它只是在预处理阶段做替换。const 是C语言中的一个类型修饰符，用来声明常量，它会为常量分配内存并指定类型。常量的值在程序运行期间不可修改。

- 类型安全

  > #define 没有类型信息，编译器无法检查类型。因此，它在某些情况下可能导致类型不匹配的问题。const 声明的常量具有类型，可以利用编译器的类型检查来避免错误。

- 作用域

  > #define 声明的常量是全局的，通常在**整个文件**中有效，甚至跨函数调用，除非使用#undef来取消定义。const 声明的常量遵循变量的作用域规则，可以限制常量的作用范围。

#define 更适用于简单的常量替换、条件编译和宏函数，它不具备类型检查，灵活性高，但容易引发错误。const 更适用于需要类型安全、具有作用域限制的常量声明，特别是在涉及到变量和复杂数据类型时。

# 常量在嵌入式中的作用

- 定义寄存器基地址

  使用# define 或const 关键字定义寄存器地址常量, 避免在代码中直接使用硬编码的地址值. 

- 定义引脚配置常量

  通常为每个引脚设置具体功能

- 状态和错误码定义
- 波特率、定时器频率等硬件配置参数
- 定义延时常量
- 通信协议中的固定值
- 中断向量表中的中断

# 错误分析

- static修饰存储空间， 不能用来定义常量

- #define NULL 0： NULL可以被重新定义， 不过会有警告， 一般不建议
- #define PI 3.14 * 2： 宏定义中， 宏名空格后的所有东西均被认为是字符串的一部分， 即使有特殊字符

2. 计算1-50的累乘并打印

> 计算思路: 从1开始, 将所得数据逆序存储, 每一位和当前阶数进行相乘, 所得结果对10取余, 作为下一位数字, 剩余进位数据, 保留和下一位相加, 本阶计算完毕后, 将进位数据按位保存到高位, 并对位置计数自加, 最后逆序输出

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define MAX_LEN 100

int main(int argc, char *argv[])
{
    int res[MAX_LEN] = {0};
    res[0] = 1;
    int digit = 1;

    //累乘1~50
    for(int i = 2; i <= 50; i++)
    {
        int carry = 0;  //进位标志
        for(int j = 0; j < digit; j++)
        {
            int temp = res[j] * i + carry;
            res[j] = temp % 10;
            carry = temp / 10;
        }
        while(carry > 0)
        {
            res[digit] = carry % 10;
            carry /= 10;
            digit++;
        }
    }

    //逆序打印结果
    printf("50! = ");
    for(int i = digit - 1; i >= 0; i--)
    {
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```
