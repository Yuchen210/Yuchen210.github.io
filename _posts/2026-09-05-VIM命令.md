# 命令模式

## 光标移动

- h 向左

- j 向下

- k 向上
- l 向右
- 0 移动到当前行行首
- $ 移动到当前行的行尾
- gg 移动到文件第一行
- G 移动到文件最后一行
- nG或:n 移动到第n行

## 文本删除

- x 删除当前光标所在字符
- dd 删除当前行
- ndd 删除从当前行开始的n行
- daw 删除当前单词

## 文本复制

- yy 复制当前行
- nyy 复制从当前开始n行
- p 在当前光标位置之后粘贴复制或删除的内容
- P 在当前光标位置之前粘贴复制或删除的内容

## 撤销与重做

- Ctrl + u 撤销上一步操作
- Ctrl + r 重做上一步撤销的操作

## 查找

- /关键字 从当前位置向下查找匹配关键词的内容
- ?关键字 从当前位置向上查找匹配关键词的内容
- n 查找下一个匹配项
- N 查找上一个匹配项

# 插入模式

- i 在当前光标位置之前插入文本
- a 在当前光标位置之后插入文本
- o 在当前行的下一行插入新行并进入插入模式
- O 在当前行的上一行插入新行并进入插入模式
- I 将光标移动到当前行的行首，并进入插入模式
- A 将光标移动到当前行的行尾，并进入插入模式

# 底行模式

- :w 保存当前编辑的文件
- :w 文件名 将文件另存为指定的文件名
- :q 退出Vim如果文件未修改
- :q! 强制退出 Vim，不保存对文件的修改
- :wq 保存文件并退出Vim
- :x 功能与 :wq 类似,保存文件并退出,但在某些情况下性能更优
- :set nu 显示行号
- :set nonu 关闭行号
- :s/旧内容/新内容 在当前行中，将第一个匹配到的旧内容替换为新内容
- :s/旧内容/新内容/g 在当前行中，将所有匹配到的旧内容替换为新内容
- :%s/旧内容/新内容/g 在整个文件中，将所有匹配到的旧内容替换为新内容
- :%s/旧内容/新内容/gc 在整个文件中，将所有匹配到的旧内容替换为新内容，替换前会询问是否确认
