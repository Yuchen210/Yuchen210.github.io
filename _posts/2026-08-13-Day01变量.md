# 变量的定义与分类

## 变量的定义

变量是用来存储数据的被命名的内存位置，需要一个有名字的，具有特定属性的存储单元来存放数据，必须**先定义后使用**或**先声明后使用**，定义时指定名字和类型，也可以指定初始值

```
int a = 10;	//初始化
int a; 		//未被初始化
a = 10;		//赋值
```

> auto：局部变量默认关键字（只能用于函数内或块内）

### 数据存储

正数的原码、反码、补码一样

负数的原码、反码、补码不一样, 原->取反加1， 补->原取反减一

| 值   |      |           |
| ---- | ---- | --------- |
| -7   | 原码 | 1000 0111 |
|      | 反码 | 1111 1000 |
|      | 补码 | 1111 1001 |

**特殊的，1000 0000 -> -0是-128的补码**

负数在计算机中以补码的形式存储，二进制下32位1，最高位为符号位， **0->正数**， **1->负数**, 而计算机在需要计算的时候需要将补码恢复成原码：

> 最高位不变，末位减一：
>
> 0b 1111 1111 1111 1111 1111 1111 1111 1110
>
> 最高位不变，剩余取反得到原码：
>
> 0b 1000 0000 0000 0000 0000 0000 0000 0001
>
> 符号位为1， 代表负数， 值为1， 所以最终值为 -1.

```c
#define ONE_BYTE 0b11111111                                                                 //8位
#define TWO_BYTES 0b1111111111111111                                                        //16位
#define FOUR_BYTES 0b11111111111111111111111111111111                                       //32位
#define EIGHT_BYTES 0b1111111111111111111111111111111111111111111111111111111111111111      //64位

#include <stdio.h>

int main(void)
{
    int _int = FOUR_BYTES;
    signed _signed = FOUR_BYTES;
    unsigned _unsigned = FOUR_BYTES;
    short _short = TWO_BYTES;
    char _char = ONE_BYTE;
    long _long = FOUR_BYTES;
    float _float = FOUR_BYTES;
    double _double = EIGHT_BYTES;
    printf("int: %d\n", _int);
    printf("signed: %d\n", _signed);
    printf("unsigned: %u\n", _unsigned);
    printf("short: %d\n", _short);
    printf("char: %c\n", _char);
    printf("long: %ld\n", _long);
    printf("float: %f\n", _float);
    printf("double: %f\n", _double);
    return 0;
}

输出：
int: -1
signed: -1
unsigned: 4294967295
short: -1
char: �		（ASCII）
long: -1
float: 4294967296.000000		
double: 18446744073709551616.000000
```

## 内存分区

![内存分区](/assets/pictures/内存分区.png)

- 栈区： 存放局部变量，从高位地址向低位地址
- 堆区：用户自己申请的地址空间， 从低位地址到高位地址
- **.bss**：初始全0，存放违背初始化的静态或全局变量
- **.data**段，存放已经初始化过的静态或全局变量
- **.rodata**段， 只读数据段，常量区， 如字符串常量
- **.text**段， 存放代码

## 全局变量

全局变量和局部变量

- 全局变量定义在函数体外面的变量， 局部变量定义在函数内部的变量
- 全局变量生命周期从程序开始到程序结束，作用域为整个程序
- 局部变量生命周期从定义开始到{}结束，作用域为{}内

## 存储类型

- auto 局部变量默认，存放在栈区
- extern 外部变量，一般声明全局变量，存放在**.bss**（未初始化）或**.data**（初始化）段
- 声明变量并不会开辟空间，只有定义后才会开辟。
- static修饰的变量为静态变量，如果被初始化过存储在**.data**段，未初始化存放在**.bss**段，初始值为0，可以修饰局部和全局变量。
- static修饰局部变量，生命周期变为全程序，作用域不变，而且只初始化一次；修饰全局变量，生命周期不变，作用域变为本文件内； 修饰函数时，限制了全局变量的作用域，只在本文件内使用。
- register：建议存储在寄存器，只做建议，最终是否在寄存器取决于编译器。

## 浮点型

- float：4字节
- double：8字节
- long double：通常12，16字节

浮点型常量默认为double，可用F或f标记为float，用L或l标记为long double

![浮点型存储规则](/assets/pictures/浮点型运算规则.png)

### 赋值

- 给浮点数赋值整数，系统自动补上小数点，如果给整型赋值小数，系统会舍去小数变为整数
- 有乘除的运算中，只要一个是浮点数，系统会将其他转成浮点数运算
- 给浮点数做赋值，如果右边是计算式，需要将右边运算数变成小数

### 输出

float 和 double

- %f：小数点格式输出，如3.1415926
- %e：科学计数法输出，3.141592e+00
- %g：根据数值大小自动选择%f或%e
- %lf：以小数点输出long double
- %le：以科学计数输出long double
- %lg：自动选择并输出long double
- %[宽度]\[精度]f:指定最小宽度和小数点后精度
- 使用-左对齐输出
