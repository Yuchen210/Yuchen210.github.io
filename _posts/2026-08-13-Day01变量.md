# 词法符号

- 关键字：由系统预定义的此法符号，有特定的含义，不允许用户重新定义：

  >
  auto break case char const continue default do double else enum extern float for goto if int long register return short signed sizeof static struct switch typedef union unsigned void volatile while
  >

- 标识符：程序员自行定义符号，命名规则如下：

  >1. 一个或多个字母、数字或下划线组成
  >2. 第一个字符必须是字母或下划线
  >3. 标识符不能和任何关键字相同
  >4. 大小写敏感
  
- 运算符：表示运算的符号
- 分隔符：分隔其他符号，包括**空格符**、**制表符**、**换行符**、**注释**

- 转义字符：**\\**是转义字符，**\n**是换行，**\t**是制表符

- 标点符号：

  >,	表示语句还未结束
  ;	表示语句结束
  ()	1.函数用小括号表示参数	2.提升优先级	3.强制类型转换
  {}	整个语句块
  []	数组

# 变量的定义与分类

## 变量的定义

变量是用来存储数据的被命名的内存位置，需要一个有名字的，具有特定属性的存储单元来存放数据，必须**先定义后使用**或**先声明后使用**，定义时指定名字和类型，也可以指定初始值

```
int a = 10;	//初始化
int a; 		//未被初始化
a = 10;		//赋值
```

### 存储类型说明

> auto：局部变量默认关键字（只能用于函数内或块内）
>
> static：声明为静态变量（生命周期为整个程序，作用域受限）
>
> extern：声明为外部变量，全局变量的默认存储类型
>
> register：建议编译器将变量存储在寄存器中，以提高访问速度
>
> typedef：定义类型

### 数据类型说明

>int：整数类型（4字节）
>
>signed：有符号整型
>
>unsigned：无符号整型
>
>short：短整型（2字节）
>
>char：字符类型（1字节）
>

>
>double：双精度浮点型（8字节）
>
>bool：布尔类型（true和false）
>
>void：空类型

### 数据存储

正数的原码、反码、补码一样

负数的原码、反码、补码不一样, 原->取反加1， 补->原取反减一

| 值   |      |           |
| ---- | ---- | --------- |
| -7   | 原码 | 1000 0111 |
|      | 反码 | 1111 1000 |
|      | 补码 | 1111 1001 |

**特殊的，1000 0000 -> -0是-128的补码**

负数在计算机中以补码的形式存储，二进制下32位1，最高位为符号位， **0->正数**， **1->负数**, 而计算机在需要计算的时候需要将补码恢复成原码：

> 最高位不变，末位减一：
>
> 0b 1111 1111 1111 1111 1111 1111 1111 1110
>
> 最高位不变，剩余取反得到原码：
>
> 0b 1000 0000 0000 0000 0000 0000 0000 0001
>
> 符号位为1， 代表负数， 值为1， 所以最终值为 -1.

```
#define ONE_BYTE 0b11111111                                                                 //8位
#define TWO_BYTES 0b1111111111111111                                                        //16位
#define FOUR_BYTES 0b11111111111111111111111111111111                                       //32位
#define EIGHT_BYTES 0b1111111111111111111111111111111111111111111111111111111111111111      //64位

#include <stdio.h>

int main(void)
{
    int _int = FOUR_BYTES;
    signed _signed = FOUR_BYTES;
    unsigned _unsigned = FOUR_BYTES;
    short _short = TWO_BYTES;
    char _char = ONE_BYTE;
    long _long = FOUR_BYTES;
    float _float = FOUR_BYTES;
    double _double = EIGHT_BYTES;
    printf("int: %d\n", _int);
    printf("signed: %d\n", _signed);
    printf("unsigned: %u\n", _unsigned);
    printf("short: %d\n", _short);
    printf("char: %c\n", _char);
    printf("long: %ld\n", _long);
    printf("float: %f\n", _float);
    printf("double: %f\n", _double);
    return 0;
}

输出：
int: -1
signed: -1
unsigned: 4294967295
short: -1
char: �		（ASCII）
long: -1
float: 4294967296.000000		
double: 18446744073709551616.000000
```
