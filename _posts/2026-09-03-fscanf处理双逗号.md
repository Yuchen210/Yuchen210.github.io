# 问题描述

在做C语言小项目时, 需要从csv文件中读取几个字符串, csv文件中的字符串是以逗号分隔, 打开文件, 显示如下:

```c
user,admin,password,1234
```

当用户不存在是时, 实际的存储为:

```c
user,,password,

//代码读取
fscanf(fp, "%*[^,],%[^,],%*[^,],%[^\n]", usr->name, usr->password);
```

而这里fscanf在读取的时候, 并没有读取成功:

注意到这里count的值为0, 证明fscanf并没有成功读取到任何数据.

# 逐步剖析

```c
fscanf(fp, "%*[^,],%[^,],%*[^,],%[^\n]", name, password);
```

- 第一个 %*[^,] 表示从开始读取字符串, 遇到逗号结束, 将字符串丢弃, 不处理逗号, 逗号仍任保留在缓冲区, 此时缓冲区为,,password,
- 之后的 , 从缓冲区读取一个逗号, 不做任何处理, 此时缓冲区为 ,password,
- 第二个 %[^,] 表示从缓冲区开始读取字符串, 遇到逗号结束, 这里因为开头就是逗号, 因此fscanf在这里匹配失败, 整个fscanf终止, 不在继续处理后面所有格式符, 已经成功赋值的参数个数是0个.

# 解决方案

简单场景下手动分割读取参数:

```c
	//读取admin信息
    fscanf(fp, "%*[^,],");  //读取user字符串
    //读取管理员用户名
    if(!fscanf(fp, "%[^,],", usr->adminName)){
        //读取失败则证明用户名为空, 添加\0,
        usr->adminName[0] = '\0';
        //读取结尾逗号
        fgetc(fp);
    }

    fscanf(fp, "%*[^,],");  //读取password字符串
    if(!fscanf(fp, "%[^\n]", usr->adminPassword)){
        //读取失败则证明密码名为空, 添加\0,
        usr->adminPassword[0] = '\0';
    }
```

复杂场景下通过fgets将文件读取到内存中, 然后在内存中实现手动分隔字符串

```c
char line[520];
fgets(line, sizeof(line), fp);
//line 里面保存整行 "user,,password,\n"
//再对line做分割处理，就不会出现fscanf直接返回0的崩溃问题。
```
