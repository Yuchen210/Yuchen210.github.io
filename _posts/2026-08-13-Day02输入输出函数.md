# 输入函数

## scanf()

- 从标准输入通常是键盘中读取格式化数据

- 原型

  ```c
  int scanf(const char *format,...)
  ```

- 参数

  > format:格式控制字符串， 类似于printf(), 如%d等, 其他参数是指向变量的指针,用来存储从输入中读取的数据

- 返回值: 返回成功读取的项数, 如果输入错误或遇到文件结束,返回负值
- scanf会跳过空白符(空格, 换行, 制表符) 等, 而不处理输入缓冲区中残留的符号
- scanf的输入非常严格,如果输入的格式与预期的格式不匹配, 会导致读取失败

## getchar()

- getchar()用于从标准输入读取一个字符

- 原型

  ```c
  int getchar(void)
  ```

- 无参数
- 返回值: 返回读取的字符(以int形式返回), 如果到达文件结束或发生错误, 则返回EOF(通常定义为-1)
- getchar()读取的是缓冲区的第一个字符,因此可能会阻塞等待用户输入, 直到输入换行符后才能读取下一个字符, 通常需要结合循环来逐字符读取.

## fgets()

- 用于从输入流读取字符串的函数。相对于 gets()，fgets() 更安全，因为它允许指定读取的最大字符数，从而避免了缓冲区溢出的问题。因此，fgets() 是推荐使用的字符串输入函数。

- 原型

  ```c
  char *fgets(char *str, int n, FILE *stream);
  ```

- 参数

  > str：指向字符数组的指针，用于存储读取到的字符串。
  > n：要读取的最大字符数（包括终止符 \0）。函数最多读取 n-1 个字符，最后一个位置留给字符串终止符 \0。
  > stream：输入流。通常为标准输入 stdin，但可以是任何文件流。

- 返回值: 返回值是指向 str 的指针，表示成功读取的数据。如果在读取过程中遇到文件结束符（EOF）或发生错误，返回 NULL。
- fgets() 会在读取到换行符、读取到 n-1 个字符，或者遇到文件结束符（EOF）时停止读取。换行符（'\n'）会被作为字符串的一部分存储在 str 中（如果读取到的话），并在字符串末尾自动添加终止符 \0。

# 输出函数

## printf()

- printf() 用于向标准输出（通常是屏幕）打印格式化的文本。

- 原型

  ```c
  int printf(const char *format, ...)
  ```

- 参数

  > format：格式控制字符串，指定如何格式化输出。常见的格式符有 %d（整型），%f（浮点数），%s（字符串）等。其他参数是需要打印的变量。

- 返回值: 返回成功打印的字符数。如果输出发生错误，返回负值。
- printf 非常灵活，可以打印各种类型的数据。需要确保格式控制符和变量类型匹配，否则会引发不正确的输出。

## putchar()

- putchar() 用于向标准输出打印一个字符。

- 原型

  ```c
  int putchar(int char)
  ```

- 参数:

  > char：要打印的字符（传递的字符以 int 形式表示，但其值应是可表示为 unsigned char 的整数）。

- 返回值: 返回输出的字符（作为 unsigned char 类型转换为 int 返回）。如果发生错误，返回 EOF。

- putchar() 常用于逐个字符的输出，例如打印字符数组中的内容。

## puts()

- puts() 用于向标准输出打印一个字符串，并在输出后自动添加换行符。

- 原型

  ```c
  int puts(const char *str)
  ```

- 参数:

  > str：要打印的字符串指针

- 返回值: 成功时返回一个非负值，失败时返回 EOF。
- puts() 在打印结束后自动添加换行符，不需要手动加 \n。适合用于简单的字符串输出。

# 错误分析

- 那些操作会导致getchar返回的字符是换行符: 只要有换行符或回车, getchar多轮读取后都有可能返回换行符
- 那些函数从标准输入中读取一个字符: getchar和scanf都可以, scanf可以通过%c来限定读取一个字符
