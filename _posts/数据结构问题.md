1. 顺序表和链表区别？

   顺序表: 数据存放在一篇连续空间中, 空间利用率高, 查找方便, 增删步骤复杂,

   链表:数据分散存放, 有指针开销, 空间利用率低, 查找依赖遍历, 效率低, 但插入和删除操作简单.

2. 栈和队列的区别？

   栈:先进后出的一种数据结构, 可用于浏览器历史记录, 深度优先算法等一种思想

   队列:先进先出的一种数据结构, 可用于任务调度, 缓冲区, 广度优先搜索等.

3. 什么叫内存泄漏？怎么避免？

   内存泄漏是指程序在运行是向操作系统申请了一块内存空间, 程序运行期间这块空间在使用结束后并没有被及时释放, 导致操作系统无法回收内存, 随着程序长时间运行, 程序所占用的空间越来越大, 有OOM的风险.

4. 什么叫段错误？怎么解决？

   段错误是指程序访问了非法的地址空间, 操作系统发出SIGSEGV信号将程序中断崩溃.

   野指针, 地址越界, 空指针解引用, 栈溢出, 指针强制类型转换等可能会遇到段错误

   可以通过gdb进行调试 和使用专业的内存分析工具, 定位内存泄漏点

5. malloc、calloc和realloc区别

   malloc: 向系统申请一块大小为size的空间, 如果申请失败则返回NULL, 申请的空间不会初始化

   calloc: 向系统申请一块空间, 其大小为size*num, 如果申请失败则返回NULL, 申请的空间会初始化为0

   realloc: 向系统申请重新分配ptr所指向的内存空间, 其大小为size, 如果申请失败则返回NULL

6. 完全二叉树？满二叉树？

   满二叉树:  一颗深度为k且有2^k^-1个节点的二叉树称为满二叉树, 强调深度为k且有2^k^-1, 每一层都满

   完全二叉树: 有n个结点的二叉树，当且仅当其每一个结点都与深度为k的满二叉树中的编号从1至n的结点一一对应时，称之为完全二叉树, 除了最后一层之外，所有层的节点都达到了最大节点数，并且最后一层的节点是从左到右依次排列的。

7. 非递归如何实现二叉树的前序遍历？

   ```c
   void NonRecursivePretraversalBiTree(BiTree T){
       if(T == NULL){
           printf("空树\n");
       }
       //初始化栈
       TreeStack S;
       InitTreeStack(&S);
       //根节点入栈
       PushStack(&S, *T);
       //定义接受弹出的树节点
       BiTNode p;
   
       //栈非空继续循环
       while(S.base != S.top){
           //先序遍历, 所以先出栈父节点
           PopStack(&S, &p);
           printf("%d ", p.data);
           //右节点先入栈, 才能后出栈
           if(p.rchild){
               PushStack(&S, *p.rchild);
           }
           if(p.lchild){
               PushStack(&S, *p.lchild);
           }
       }
   }
   ```

8. 冒泡排序的思想？

   依次进行比较, 每次循环确定一个最大或最小值.

   外层循环需要进行n-2次, 内次循环需要进行n-i-2次

9. 选择排序的思想？

   从数组1开始, 每次循环确定一个最小值, 将最小值和前一位进行比较, 如果小于则进行调换, i<length-1, 确定数组有序

10. 说下二分查找？

    二分查找: 对于一个有序数组, 如果需要查找的值小于数组中间值, 那么递归从他的左边进行查找,大于则递归从右边进行查找.相等则确认找到

11. 哈希表为什么查找效率高？

    哈希表存储的是元素的索引, 需要查找时只需要计算出对应元素的哈希值, 以哈希值作为下标进行查找, 时间复杂度为O(1). 因此效率高

12. 队列和栈的区别？

    栈:先进后出的一种数据结构, 可用于浏览器历史记录, 深度优先算法等一种思想

    队列:先进先出的一种数据结构, 可用于任务调度, 缓冲区, 广度优先搜索等.

13. 快速排序思想？

    快速排序是一种利用分治思维的排序, 每次排序时, 选取一个基准值(一般选择中间大小), 将大于基准值的放在一边, 小于基准值的放在另一边, 然后递归, 分别对左右进行排序, 直到数组有序

15. 时间复杂度什么作用？

    时间复杂度可以用来评判一个算法的执行效率, 时间复杂度越高的程序, 在遇到大量数据时所需要的处理时间会更高

17. 数据结构在学什么？

    数据结构在学习数据在计算机中的关系和存储方式, 关系可以分为集合, 线性, 树状和图, 存储方式可以分为顺序性存储, 链式存储, 散列存储, 索引存储

18. 二叉树的遍历？

    二叉树分为先序, 中序和后序遍历, 先序遍历为根左右, 中序为左根右, 后序为左右根

19. 如何实现单链表的倒置？

    定义三个指针pre, cur和next, 令pre为NULL, cur指向第一个节点, 如果cur不为空, 则next = cur->next, cur->next = pre; pre = cur; cur = next, 持续循环, 最后pre为新的第一个节点

20. 插入排序的思想？

    从数组的下标1开始, 依次将元素和之前的进行对比, 如果无序则继续对比, 然后将元素对应的位置之后的数据依次后移, 将元素插入到对应位置, 遍历结束后有序

21. 内部排序和外部排序？

    内部排序: 整个排序过程中所有待排序记录全部存放在内存中的排序

    外部排序: 待排序记录数量很大, 无法全部放入内存, 排序期间需要借助外存, 在内外存之间交换数据完成排序

22. 排序算法的稳定性？哪些是稳定的？

    序列中有两个相等元素A~i~和A~j~, 排序前A~i~在A~j~前面, 排序后其顺序不变. 

    稳定排序: 直接插入排序, 冒泡排序, 归并排序, 基数排序

    不稳定排序: 快速排序, 堆排序, 简单选择排序, 希尔排序

23. 如何将两个有序的单链表合并成一个有序的单链表？

```c
void MergeLinkList(Linklist La, Linklist Lb, Linklist Lc){
    Linklist pa = La->next;
    Linklist pb = Lb->next;
    Linklist pc;
    pc = Lc = La;
    while(!pa && !pb){
        if(pa->data < pb->data){
            pc->next = pa;
            pc = pa;
            pa = pa->next;
        }else{
            pc->next = pb;
            pc = pb;
            pb = pb->next;
        }
    }
    pc->next = pa? pa : pb;
    free(Lb);
}
```
