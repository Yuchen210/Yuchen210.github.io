Linux进程线程常见问题
1  什么是程序？什么是进程？进程和程序的区别？

程序是存储在磁盘中的可执行文件, 不占用CPU, 内存资源, 静态存储, 长期存在, 只占用磁盘空间, 没有状态, 多个程序之间相互独立, 无直接关联

进程是程序的动态执行过程, 是程序运行时的示例, 占用CPU, 内存, IO等系统资源, 有生命周期, 动态存在, 有状态, 随系统调度改变, 每个进程都有独立的地址空间和资源, 进程间默认不共享数据, 需通过进程通信机制实现

2  什么是进程号？什么是父进程号？

进程号是进程在运行时操作系统分配给进程的唯一标识符, 大于等于0, 

父进程号是创建当前进程的父进程的进程号, Linux中, 0号进程负责CPU调度, 1号进程负责创建其他进程

3  Linux系统中进程有几种类型？分别是什么？

前台进程:由shell维护, 依赖与用户进行交互的进程, 运行在前台终端

批处理进程: 无需用户实时交互, 按预设任务序列自动运行, 通常在后台执行, 优先级较低, 通过脚本或任务调度工具启动

守护进程: 系统启动时自动运行的后台进程，独立于终端，通常随系统启动而启动，随系统关闭而终止，用于提供持续服务, 运行时脱离终端

4  Linux系统中的进程有几种状态？分别是什么？这几种状态如何切换？

运行态, 可中断睡眠态, 不可中断睡眠态, 停止态, 僵尸态, 死亡态

运行态程序在遇到条件后可转为睡眠态, 停止态和僵尸态,  睡眠态和停止态在条件满足后可继续转换为运行态, 僵尸态可转换为死亡态

5  在Linux系统中如何创建一个子进程？描述创建过程？

可以使用fork函数

fork函数返回一个pid_t类型的值, 如果成功会返回两个, 在父进程中返回子进程真实的PID, 在子进程中返回0, 失败返回-1, 

fork函数执行后, 操作系统会为子进程分配虚拟空间, 实际物理空间遵循写时拷贝原则

6  什么是孤儿进程？什么是僵尸进程？如何避免僵尸进程的产生？

孤儿进程是指父进程早于子进程先一步退出或崩溃, 子进程变成孤儿进程被1 号进程收养, 子进程的资源由1号进程进行回收

僵尸进程: 子进程运行结束后, 父进程没有及时回收子进程的资源, 导致子进程进入僵尸态

可以在父进程中通过wait等函数调用回收子进程的资源, 也可以通过kill命令杀死父进程, 让僵尸进程被1号进程收养, 然后由1号进程负责回收

7 exec函数族中的函数的作用是什么？

exec函数族中的函数可以将程序的可执行代码替换成目标代码, 如果exec函数执行成功, 那么会执行目标代码, 没有返回值, 如果执行失败则返回-1

8 exit()和_exit()的作用是什么？有什么区别？

exit是库函数, _exit是系统调用, 两个都是退出当前进程, 但是exit会进行资源回收, 如缓冲区刷新等, _exit是系统调用, 不会处理缓冲区和资源回收, 

9  什么是阻塞函数？什么是非阻塞函数？

阻塞函数是运行该函数后, 程序会阻塞等待响应的运行条件, 等条件满足后才会继续执行

非阻塞函数是指程序运行后, 直接判断条件是否满足,无论是否满足则直接执行后续的程序, 不会进入阻塞等待

10  什么是守护进程？如何创建一个守护进程（写出创建步骤）

守护进程是随系统开机时启动, 系统关闭时退出, 运行在后台提供服务的进程

创建守护进程: 在程序中调用fork函数, 父进程退出, 子进程调用setsid函数, 将进程提升为进程组组长, 脱离原来的进程, 然后用chdir函数更改当前目录到不会影响其他程序的目录, 调用umask函数设置默认的文件掩码, 然后关闭所有从父进程中继承的文件描述符, 重定向或关闭三个标准文件描述符, 随后启动自己真实的服务, 运行在后台

11 什么是线程？如何创建线程？程序中创建线程需要注意什么？编译有线程的程序时注意什么？

线程是共享资源的轻量级进程, 共享进程的资源, 拥有独立的栈空间.

可以使用pthread_creat函数创建线程, 创建线程时应注意线程的属性, 创建后需要及时回收线程的资源,

编译有线程的程序时, 应注意头文件#include <pthread.h>, 线程由动态库libpthread.so提供, 在使用命令编译时应添加-lpthread参数, 索引动态库

12  Linux系统中已经有了进程？为什么还要引入线程？线程和进程的区别有哪些？

进程拥有独立的内存空间, 文件描述符等资源, 切换开销大, 线程与进程共享这些核心资源, 切换开销小, 效率高, 因此引入了线程

线程仅拥有独立的栈, 程序计数器, 开销小, 仅需保存少量上下文信息, 可直接通过共享内存通信, 一个线程崩溃可能导致整个进程崩溃

进程有独立的资源, 开销大, 需通过进程间通信机制, 一个进程崩溃通常不影响其他进程

13  线程间的数据通信如何实现？线程间的同步如何实现？线程间的互斥如何实现？

线程间通信可以借助共享地址空间, 通过全局变量, 堆内存, 线程传参通信

线程间同步可通过条件变量实现

线程的互斥可以通过信号量和互斥锁实现

14  Linux系统中的进程间通信方式有几种？分别是什么？

无名管道, 有名管道, 信号, 消息队列, 共享内存, 信号量集和socket

15  使用任意一种进程间的通信方式，实现两个进程间数据的交换（手撕代码）

有名管道:

读进程

```c
#include <stdio.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <unistd.h>
#include <fcntl.h>
#include <stdlib.h>

    // 读进程
int main(int argc, char *argv[])
{
    if (argc != 2)
    {
        printf("Please check arguments\n");
        return -1;
    }

    // 打开管道文件会阻塞等待其他进程以另一种方式打开
    int read_fd = open(argv[1], O_RDONLY);
    if (read_fd == -1)
    {
        perror("Read process open fifo failed");
        return -1;
    }

    char buffer[BUFSIZ] = {0};
    ssize_t read_return = 0;
    read_return = read(read_fd, buffer, sizeof(buffer));
    if (read_return == -1)
    {
        perror("Read process read file failed");
        return -1;
    }
    printf("Read process read success:\n");
    printf("%s", buffer);
    close(read_fd);
    unlink(argv[1]);
    exit(EXIT_SUCCESS);
    return 0;
}
```

写进程:

```c
#include <stdio.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <unistd.h>
#include <fcntl.h>
#include <stdlib.h>

// 写进程
int main(int argc, char *argv[])
{
    if (argc != 2)
    {
        printf("Please check arguments\n");
        return -1;
    }
    if (mkfifo(argv[1], 0666) == -1)
    {
        perror("Create fifo failed");
        unlink(argv[1]);
        return -1;
    }
    // 打开管道文件会阻塞等待其他进程以另一种方式打开
    int write_fd = open(argv[1], O_WRONLY);
    if (write_fd == -1)
    {
        perror("Write process open fifo failed");
        return -1;
    }

    char buffer[] = "hello world\n";
    write(write_fd, buffer, sizeof(buffer));
    close(write_fd);
    exit(EXIT_SUCCESS);
    return 0;
}
```

16  什么是同步通信？什么是异步通信？

同步通信: 发送方发送数据后, 阻塞等待接收方接收并处理完毕, 收到应答之后才继续执行后续代码, 发送方在等待期间不做别的任务, 如管道

异步通信: 发送方发送数据之后, 不用等待对方处理和应答, 直接返回继续执行后续代码, 如信号, 消息

16   什么是信号通信？哪些函数可以发出信号？

信号是中断的一种软件模拟, 信号通信是依靠操作系统定义的信号集合进行通信, 可以使用kill -l命令查看可以使用的信号

kill函数, raise函数

17   在linux系统中，进程对信号的响应方式有哪些？

忽略: 不做任何处理, 丢弃信号, 默认: 按照操作系统默认的操作处理信号, 捕获: 注册信号处理函数, 按照注册的函数处理对应信号

SIGKILL和SIGSTOP不能被捕获和忽略

18 共享内存和消息队列这两种通信方式有何区别？

共享内存适合对速率和实时性有要求的场景, 需要手动处理同步和互斥机制, 没有额外的拷贝开销

消息队列适合异步通信, 高并发场景, 可以根据消息类型来进行筛选处理, 有完整的同步机制, 需要进行额外的拷贝

19 查看Linux系统进程的方法？

可以使用ps, top和htop命令查看进程

20  讲讲共享内存的优缺点？

共享内存会在内核中创建共享内存, 对应进程映射到自己虚拟内存中即可访问, 适合高速和实时性高的场景, 共享内存没有完整的同步,互斥和资源回收机制, 需要手动进行处理

21 在Linux中造成死锁的3种操作？

锁的顺序不一致: A先拿1, 再拿2, b先拿2, 再拿1

占有并等待: A先拿着1, 不释放, 再去申请另一把

等待锁的线程持有资源, 而资源持有者再等待该线程, 或者锁使用完忘记unlock

22 线程join和detach区别？

join是等待线程运行完成后, 主动去回收线程的资源

detach是将线程设置为分离态, 线程运行完成后由操作系统进行回收, 无需手动回收资源

23 什么是进程的上下文切换？

CPU从一个进程切换到另一个进程运行时, 需要保存当前进程的运行环境, 再加载新进程的运行环境就叫上下文切换.

上下文里包含: 寄存器, 进程状态, 内存相关, 内核栈

24 并行和并发的区别？

并发: 多个任务交替使用同一个CPU核心, 宏观上看起来同时在跑

并行: 多个任务在多个CPU核心上, 同一时刻真正一起执行
