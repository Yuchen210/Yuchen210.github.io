# 数学计算

- 加法运算符+

- 减法运算符-

- 乘法运算符* 遵循基本的数学优先级, 乘法会比加法或减法优先执行

- 除法运算符/ 对于整数除法, 结果为整数, 会舍弃小数部分, 对于浮点数, 会保留小数部分. 除数为0 时会导致除零错误

- 取余运算符% 取余运算符仅适用于整型.

- 赋值运算符+= -= *= /= 

- 自增与自建运算符

  > 自增++ 前置先自加, 再进行其他运算,后置先运算, 运算完成后在自加
  >
  > 自减-- 前置先自减, 再进行其他运算,后置先运算, 运算完成后在自减

- 常见错误:

  > 除以零错误
  >
  > 整数除法的精度丢失
  >
  > 取余运算不能用于浮点数

# 位运算

- 按位与&: 有0为0, 通常保留或清除某些位数据

  ```c
  1001
  0010
     &
  0000
  ```

- 按位或|: 无1为0, 通常对某些特定为进行设置

  ```c
  1001
  0010
     |
  1011
  ```

- 按位异或^: 相同为0, 不同为1

  ```c
  1001
  0010
     &
  1011
  ```

- 取反~

  ```c
  32位
  0000 0000 0000 0000 0000 0000 0000 1001 (9)
  									  ~
  1111 1111 1111 1111 1111 1111 1111 0110 (补码, 取反+1后 -10)
  ```

- 左移<<: 最高位舍去, 补0, 有符号左移未定义, 不要写

  ```c
  char a = 9 (0000 1001)
  a = a << 1;
  0001 0010
  ```

- 右移>>: 

  1. 无符号类型, 逻辑右移, 最低为舍去, 最高位补0

  ```c
  unsigned char a = 9 (0000 1001)
  a = a >> 1;
  0000
  ```

  2. 有符号类型, 编译器标准行为算数右移, 左边补符号位

  - 正数: 符号位是0, 左边补0, 和逻辑右移一样

    ```c
    char a = 9 (0000 1001)
    a = a >> 1;
    0000 0100
    ```

  - 负数: 符号位是1, 左边补1

    ```c
    char a = -9 (1000 1001)
    a = a >> 1;
    1100 0100
    ```

# 逗号运算符

表达式1, 表达式2, 表达式3, ... , 表达式n;

运算规则: 从左至右一次执行, 会将表达式n的值作为整个表达式的返回值

```c
int a = (1, 2, 3, 4); //a = 4
int b = 1, 2, 3, 4; //b = 1
```

# 三目运算符

表达式1?表达式2:表达式3

判断表达式1是否成立, 如果成立,执行表达式2并将表达式2作为最终结果, 否则执行表达式3, 并将表达式3作为最终结果

- 测试1-50的累乘，用double和数组方法区别是什么

  > double会超出数值范围, 造成数据丢失, 所以需要用数组方法
  >
  > 第一层循环: i->1-50内部: 
  >
  > 每一位与当前j相乘, 相乘后
  ```c
  #include <stdio.h>
  #include <stdlib.h>
  #include <stdbool.h>
  
  int main(int argc, char *argv[])
  {
      int num[100] = {0};
      int carry = 0;
      int digit = 1;
      num[0] = 1;
      //外部循环从1遍历到50
      for(int i = 2; i <=50; i ++)
      {
          //每一位与当前阶数相乘, 产生进位, 并写如当前位
          for(int j = 0; j < digit; j++)
          {
              int temp = num[j] * i + carry;
              num[j] = temp % 10;
              carry = temp / 10;
          }
          //进位对10取余得到当前位, 进位除以10得到下一位的进位, 标志位自加
          while(carry > 0)
          {
              num[digit] = carry % 10;
              carry /= 10;
              digit++;
          }
      }
      printf("50! = ");
      //逆序打印结果
      for(int i = digit -1; i >= 0; i--)
      {
          printf("%d", num[i]);
      }
      printf("\n");
      return 0;
  }
  ```
