# GCC

常用选项

-o 指定输出文件名

-c 生成.o文件, 不进行链接

-E 预处理

-S 编译

-g 生成调试信息

-Wall 开启大部分常见告警

-std 指定变成语言标准 gcc -std=c99

# GDB

进入程序

gdb app

常用命令

run/r 运行程序, 直到断点或程序结束

continue/c 继续运行, 直到下一个断点或结束

list/l 列出源代码, 

> l 默认当前行附近
>
> l main 列出main函数代码

break/b

> b n 在第n行设置短短
>
> b main 在main函数设置断点

info b 查看已设置断点的信息

delete/d d 2 删除指定编号的断点

next/n 逐过程调试, 不进入函数内部

step/s 单步调试, 进入函数内部

print/p p n查看变量n的值

display display n每次程序停止时自动显示变量n的值

quit/q 退出gdb
